Редактор схем — .schem и .schematic онлайн

Поддерживаются Minecraft Bedrock Edition и Java Edition, а также все популярные и малоизвестные серверные ядра для обеих версий: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina и другие. Полный список.

Схемы — сжатый gzip big-endian NBT. Откройте современный файл WorldEdit .schem (формат Sponge Schematic) или старый .schematic MCEdit, чтобы проверить палитру, размеры, смещения, блочные сущности и метаданные, изменить теги и сохранить файл для //paste.

Два формата семейства схем

ФорматРасширениеОсновные теги
Sponge Schematic v2 (WorldEdit 7).schemVersion, DataVersion, Width, Height, Length, Palette, BlockData, BlockEntities, Offset, Metadata
Sponge Schematic v3.schemТе же данные внутри compound-тега Schematic; Blocks содержит Palette и Data
Старый формат MCEdit.schematicWidth, Height, Length, Blocks, Data, Entities, TileEntities, Materials

BlockData в формате Sponge — byte-массив varint-индексов палитры, а не один байт на блок: длинные id занимают несколько байтов. Старый формат хранит числовые id в Blocks и метаданные по полбайта в параллельном Data, поэтому на новых версиях часть данных теряется.

Что имеет смысл менять вручную

  • Записи палитры. Замена minecraft:oak_planks на minecraft:spruce_planks в Palette меняет все соответствующие блоки.
  • Смещение и начало координат. Offset определяет положение вставки относительно игрока.
  • Блочные сущности. Инвентари сундуков, строки табличек и данные спавнеров находятся в BlockEntities.
  • Метаданные. Metadata хранит автора и исходную точку WorldEdit; перед публикацией их можно очистить.
  • DataVersion. Показывает версию Minecraft, создавшую схему, и помогает объяснить ошибки неизвестных блоков.

Совместимость загрузчиков

WorldEdit и FastAsyncWorldEdit читают .schem из plugins/WorldEdit/schematics/; старые .schematic преобразуются при загрузке. Litematica использует собственный NBT-контейнер .litematic, который тоже открывается здесь, но имеет другую схему. Редактор сохраняет любой вариант как gzip NBT, ожидаемый загрузчиком.

Частые вопросы

Можно открыть .schem без сервера и WorldEdit?

Да. .schem — обычный gzip big-endian NBT, который открывается в браузере без установки программ.

Почему схема вставляется с неверными блоками?

Обычно из-за несовпадения версий. Проверьте DataVersion и палитру: новая схема может содержать состояния блоков, неизвестные старому серверу.

Можно изменить размер схемы?

Не одной правкой Width/Height/Length. Размер BlockData должен соответствовать объёму, поэтому размеры и данные меняются вместе в WorldEdit.

Открываются файлы .litematic?

Да, как NBT. У Litematica собственная схема тегов, поэтому отображается её исходная структура, а не палитра Sponge.
