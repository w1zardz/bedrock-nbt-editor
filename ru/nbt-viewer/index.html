Чтение чужого файла

Часто файл NBT открывают для диагностики: какая версия его записала, почему мир не загружается, что на самом деле находится в присланной схеме. Средство просмотра показывает точный тип каждого тега, поэтому TAG_Byte со значением 1 можно отличить от TAG_Int со значением 1. Для Minecraft это важное различие, которое обычно теряется в текстовых дампах.

  • Метка типа в каждой строке: Byte, Short, Int, Long, Float, Double, Byte[], String, List, Compound, Int[], Long[].
  • Полные 64-битные Long отображаются точно, поэтому значения сидов и частей UUID не округляются.
  • Поиск по всему дереву по имени или значению тега с переходом прямо к совпадению.
  • Определённый формат отображается на панели файла: версия игры, порядок байтов, сжатие и версия хранилища Bedrock.
  • Экспорт SNBT преобразует весь документ в текст, который можно сравнить, вставить в команду или передать другому инструменту.

NBT и SNBT

SNBT — текстовая форма NBT, которую выводит /data get и принимают команды. Типы сохраняются с помощью суффиксов: 3b — Byte, 3s — Short, 3L — Long, 3.0f — Float, 3.0d — Double, [I;1,2,3] — массив Int. Кнопка экспорта создаёт именно такой текст. Двоичный файл можно вставить в командный блок, добавить в git и сравнить построчно.

JSON не заменяет SNBT: в нём один числовой тип и нет массивов Byte, поэтому преобразование NBT в JSON незаметно удаляет важные для Minecraft различия. По этой причине инструмент экспортирует SNBT, а не JSON.

Поддерживаемые файлы

Открывается любой файл, полезная нагрузка которого состоит из одного документа NBT: level.dat из Java и Bedrock, playerdata, servers.dat, hotbar.nbt, idcounts.dat, raids.dat, scoreboard.dat, данные карт, структуры .nbt, .schem и .schematic, .mcstructure, .litematic, извлечённые данные чанков и дампы пакетов. Из контейнеров, таких как регионы .mca, архивы .mcworld и папки LevelDB, сначала нужно извлечь отдельный документ.

Частые вопросы

Можно ли просмотреть файл NBT без редактирования?

Да. Редактор записывает файл только после нажатия кнопки Сохранить и скачать и никогда не меняет исходный перетащенный файл.

Можно ли преобразовать NBT в JSON?

Инструмент экспортирует SNBT, который сохраняет типы тегов. JSON объединяет Byte, Short, Int, Long и Float в один числовой тип и не поддерживает массивы Byte, поэтому не подходит для обратимого преобразования данных Minecraft.

Почему файл определён как другая версия игры?

Формат определяется по байтам, а не по расширению. Если файл отображается как Java вместо ожидаемого Bedrock, обычно он действительно относится к другой версии либо представляет собой фрагмент, который случайно удалось разобрать. При предупреждении о концевых байтах проверьте указанные смещения.

Файл какого размера можно открыть?

Документы размером в несколько мегабайт обрабатываются нормально: массивы хранятся как типизированные, а дерево отображается по мере раскрытия, поэтому на странице существуют только открытые строки.
