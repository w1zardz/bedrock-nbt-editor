Чтение неизвестного файла

NBT часто открывают для диагностики: какая версия записала файл, почему мир не загружается, что находится в полученной схеме. Просмотрщик показывает точный тип каждого тега и отличает TAG_Byte со значением 1 от TAG_Int со значением 1 — важное для Minecraft различие, которое обычно теряется в текстовых дампах.

  • Тип у каждой строки: Byte, Short, Int, Long, Float, Double, Byte[], String, List, Compound, Int[], Long[].
  • Точные 64-битные long, поэтому сиды и части UUID не округляются.
  • Поиск по имени или значению во всём дереве с переходом к совпадению.
  • Определённый формат в панели файла: редакция, порядок байтов, сжатие и версия хранилища Bedrock.
  • Экспорт SNBT для сравнения текста, вставки в команду или передачи другому инструменту.

NBT и SNBT

SNBT — текстовая форма NBT, которую выводит /data get и принимает команда. Суффиксы сохраняют типы: 3b — byte, 3s — short, 3L — long, 3.0f — float, 3.0d — double, [I;1,2,3] — int-массив. Экспорт создаёт такой текст для командного блока или построчного сравнения в git.

JSON не заменяет SNBT: в нём один числовой тип и нет byte-массивов, поэтому преобразование теряет важные для Minecraft различия. Редактор экспортирует SNBT, а не JSON.

Поддерживаемые файлы

Любые данные, состоящие из одного документа NBT: Java- и Bedrock-файлы level.dat, playerdata, servers.dat, hotbar.nbt, idcounts.dat, raids.dat, scoreboard.dat, карты, структуры .nbt, .schem и .schematic, .mcstructure, .litematic, извлечённые чанки и дампы пакетов. Из контейнеров .mca, архивов .mcworld и папок LevelDB сначала нужно извлечь один документ.

Частые вопросы

Можно просмотреть NBT-файл без редактирования?

Да. Новый файл создаётся только после нажатия «Сохранить и скачать», а исходный файл не изменяется.

Можно преобразовать NBT в JSON?

Редактор экспортирует SNBT с сохранением типов тегов. JSON объединяет byte, short, int, long и float в один тип числа и теряет byte-массивы, поэтому не подходит для обратимого преобразования данных Minecraft.

Почему определилась не та редакция?

Формат определяется по байтам, а не расширению. Если вместо Bedrock указан Java, файл обычно взят из другой редакции либо его фрагмент случайно разобран. При предупреждении проверьте смещения и лишние байты.

Какой максимальный размер файла?

Документы размером в несколько мегабайт поддерживаются: массивы остаются типизированными, а дерево выводится лениво только для раскрытых строк.
