NBTExplorer онлайн — альтернатива в браузере

Поддерживаются Minecraft Bedrock Edition и Java Edition, а также все популярные и малоизвестные серверные ядра для обеих версий: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina и другие. Полный список.

NBTExplorer — известный настольный редактор тегов Minecraft, которому нужны .NET или Mono, скачивание и компьютер. Здесь те же основные операции — дерево тегов, изменение значений, добавление и удаление тегов — выполняются в браузере на любой ОС, включая телефоны. Также поддерживаются little-endian файлы Bedrock, которые NBTExplorer не читает.

Если нужно просмотреть всю папку региона и открывать чанки по координатам, удобнее настольная программа. Если требуется открыть один level.dat, файл игрока, схему или мир Bedrock на любом устройстве, браузерный редактор работает быстрее и поддерживает обе редакции.

Переход с настольной программы

  • Дерево работает так же. Раскрывайте compound-теги и списки, нажимайте значение для изменения, используйте + и × для структуры.
  • Типы строго проверяются. Byte остаётся byte; значения вне диапазона отклоняются, а не обрезаются.
  • Сохранение создаёт загрузку, а не перезаписывает исходный файл, поэтому оригинал остаётся резервной копией.
  • Сжатие сохраняется. gzip-файл снова записывается с gzip и принимается игрой без ручного сжатия.
  • Bedrock работает сразу. Не нужен отдельный инструмент или hex-редактор для исправления длины заголовка.

Когда нужны другие инструменты

Используйте NBTExplorer или NBTStudio для массового просмотра регионов, Amulet или MCA Selector для правки чанков и очистки мира, WorldEdit для геометрии. Эта страница подходит для задачи «открыть один файл, изменить теги и сохранить», особенно если настольная программа не принимает Bedrock.

Частые вопросы

Есть официальная веб-версия NBTExplorer?

Нет. NBTExplorer — настольное приложение; это независимый редактор для тех же повседневных задач в браузере с дополнительной поддержкой Bedrock.

Он работает на macOS и Linux без Mono?

Да. Это веб-страница, работающая в современном браузере на macOS, Linux, Windows, Android и ChromeOS.

Можно открыть целый файл региона, как в NBTExplorer?

Нет. Редактор обрабатывает один документ NBT. Сначала извлеките чанк из .mca, затем откройте его данные здесь.

Безопасно открывать единственную копию сохранения?

Редактор не перезаписывает открытый файл, а возвращает изменения отдельной загрузкой. Тем не менее всегда храните собственную резервную копию.
