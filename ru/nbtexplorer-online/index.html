NBTExplorer онлайн — альтернатива в браузере

Поддерживаются Minecraft Bedrock Edition и Java Edition, а также все популярные и малоизвестные серверные ядра для обеих версий: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina и другие. Полный список.

NBTExplorer — знакомый многим игрокам Minecraft настольный редактор тегов, для которого нужны .NET или Mono, скачивание и компьютер. Эта страница выполняет ту же работу в браузере: показывает дерево тегов, позволяет редактировать значения, добавлять и удалять теги. Она работает в любой операционной системе, включая телефоны, и читает файлы Bedrock с порядком байтов little-endian, которые NBTExplorer не поддерживает.

Если нужно просматривать целую папку регионов и открывать чанки по координатам, настольный инструмент удобнее. Если требуется открыть один файл — level.dat, файл игрока, схему или мир Bedrock — на доступном устройстве, браузерный редактор работает быстрее и поддерживает версии игры, с которыми настольный инструмент не работает.

Переход с настольного инструмента

  • Дерево работает так же. Раскрывайте Compound и списки, нажимайте значение для изменения, используйте + и × для управления структурой.
  • Типы контролируются так же. Byte остаётся Byte; значение вне допустимого диапазона отклоняется, а не обрезается незаметно.
  • Сохранение скачивает файл, а не перезаписывает его на месте. Перетащенный файл не меняется, поэтому исходная копия сохраняется автоматически.
  • Сжатие сохраняется. Файл gzip скачивается с тем же сжатием, поэтому игра принимает его без ручного повторного сжатия.
  • Bedrock поддерживается сразу. Не нужен отдельный инструмент или hex-редактор для исправления длины заголовка после изменения.

Когда нужны другие инструменты

Используйте NBTExplorer или NBTStudio для массового просмотра регионов. Для точечного изменения чанков и очистки мира подойдут Amulet или MCA Selector. Для геометрических операций используйте WorldEdit. Эта страница подходит для задачи "открыть один файл, изменить эти теги и получить файл обратно", а также для файлов Bedrock, которые настольные инструменты не открывают.

Частые вопросы

Существует ли официальная веб-версия NBTExplorer?

Нет. NBTExplorer — настольное приложение. Это независимый редактор, который выполняет те же повседневные задачи в браузере и дополнительно поддерживает Bedrock.

Работает ли редактор в macOS и Linux без Mono?

Да, это веб-страница. Она работает в любом современном браузере в macOS, Linux, Windows, Android или ChromeOS.

Можно ли открыть целый файл региона, как в NBTExplorer?

Нет. Редактор обрабатывает по одному документу NBT. Сначала извлеките чанк из .mca, затем перетащите сюда его данные.

Безопасно ли редактировать единственную копию сохранения?

Редактор никогда не перезаписывает открытый файл: изменения скачиваются как новый файл. Тем не менее всегда храните собственную резервную копию.
