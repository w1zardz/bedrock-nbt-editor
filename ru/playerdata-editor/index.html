Редактор playerdata — файлы игроков Minecraft

Поддерживаются Minecraft Bedrock Edition и Java Edition, а также все популярные и малоизвестные серверные ядра для обеих версий: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina и другие. Полный список.

Java Edition хранит каждого игрока в gzip big-endian NBT-файле world/playerdata/<uuid>.dat: инвентарь, эндер-сундук, позицию, измерение, здоровье, голод, опыт и атрибуты. Откройте файл, чтобы переместить застрявшего игрока, удалить вызывающий сбой предмет или сбросить параметры. Сервер должен быть остановлен либо игрок отключён.

В 1.20.5 структура предметов изменилась: пользовательские данные перенесены из compound-тега tag в отдельные components. Редактор открывает оба варианта.

Типичные исправления

  • Игрок застрял или бесконечно падает. Задайте безопасные координаты в Pos как три double в порядке X, Y, Z и очистите Motion, если там слишком большое значение.
  • Клиент вылетает при входе. Обычно причина в некорректном предмете. Удалите проблемную запись из Inventory, не очищая весь список.
  • Неверное измерение после ошибки портала. Задайте Dimension как minecraft:overworld и укажите подходящий Pos.
  • Игрок застрял в режиме наблюдателя. Задайте playerGameType 0 для выживания или 1 для творчества.
  • Остались модификаторы удалённого плагина. Удалите устаревшие записи из Attributes.

Отключите игрока перед изменением

Сервер держит состояние игрока в памяти и записывает его при выходе и автосохранении. Если игрок онлайн, изменения будут перезаписаны; одновременное сохранение может обрезать файл. Отключите игрока или остановите сервер, скопируйте и измените файл, затем верните его до нового подключения. Сохраните оригинал до успешного входа.

Серверы Bedrock используют другую структуру: данные игроков находятся в LevelDB мира в ключах вроде player_<uuid>, значения которых содержат little-endian NBT. Извлечённое значение открывается как Bedrock без заголовка.

Частые вопросы

Как определить файл нужного игрока?

Файлы названы по UUID. Найдите UUID игрока через просмотрщик Mojang API либо отсортируйте playerdata/ по времени изменения и сопоставьте с последним входом.

Можно выдать себе предметы через playerdata?

На своём сервере — да: добавьте запись в Inventory с id, Count и Slot. На чужом сервере это несанкционированное вмешательство, а работающий сервер всё равно перезапишет файл.

Почему изменение исчезло?

Сервер или игрок был онлайн. При следующем сохранении состояние из памяти перезаписало файл.

В Bedrock используется такой же playerdata?

Нет. Bedrock хранит игроков в LevelDB мира, а не в отдельных UUID-файлах. Извлечённый little-endian NBT открывается здесь.
