Все файлы NBT, которые создаёт Minecraft

NBT (Named Binary Tag) — единый формат с несколькими вариантами кодирования, а каждое издание Minecraft, программа запуска и серверное ядро используют разные их сочетания. Редактор поддерживает все варианты и определяет нужный по самим байтам, поэтому перед открытием файла знать его разновидность не требуется.

Как изменить файл NBT

  1. Скопируйте файл с сервера или устройства. На серверах Java он находится в world/, на серверах Bedrock — в worlds/YourWorld/, на Android — в games/com.mojang/minecraftWorlds/<id>/. Сначала остановите сервер, чтобы во время копирования в файл ничего не записывалось.
  2. Перетащите файл в редактор. Метка над деревом покажет определённые параметры: издание, кодирование, сжатие, а для Bedrock — версию хранилища из заголовка.
  3. Внесите изменения. Нажмите значение, чтобы изменить его на месте. Поиск переходит к тегу по имени или значению, + добавляет теги в любой Compound или List, а × удаляет их.
  4. Сохраните и скачайте. По умолчанию формат вывода и сжатие совпадают с исходным файлом, поэтому обычное редактирование сохраняет его двоичный формат.
  5. Верните файл на место и перезапустите сервер. Храните исходную копию, пока мир не загрузится и вы не убедитесь, что всё работает правильно.

Чем отличается этот редактор

Пять кодировок в одной области загрузки

Java big-endian, Bedrock little-endian, сетевой NBT Bedrock с varint, сетевой NBT с безымянным корнем из Java 1.20.2+ и level.dat Bedrock с заголовком. Формат определяется, а не угадывается.

gzip и zlib в браузере

Распаковка и повторное сжатие выполняются нативным API Compression Streams, поэтому после обработки level.dat Java игра принимает файл без изменений формата.

Настоящие 64-битные Long

Значения TAG_Long хранятся как BigInt. Сиды миров и части UUID не искажаются округлением чисел с плавающей точкой, из-за которого ошибаются многие браузерные инструменты NBT.

Правильное кодирование строк

Java записывает модифицированный UTF-8 (CESU-8), Bedrock — стандартный UTF-8. Редактор кодирует строки по правилам издания, поэтому эмодзи и нелатинские названия миров сохраняются.

Работа с большими файлами

Массивы хранятся в типизированных массивах, а дерево отрисовывается по мере необходимости, по 200 элементов. NBT чанка размером в мегабайт открывается без зависания вкладки.

Поиск по всему дереву

Найдите любой тег по имени или значению в любой части файла и сразу перейдите к нему с раскрытым путём.

Экспорт SNBT

Экспортируйте всё дерево как SNBT — текстовый формат команд /data и датапаков — для сравнения, передачи или вставки в команду.

Преобразование форматов

Прочитайте файл Bedrock и сохраните его как Java big-endian gzip или наоборот. Это полезно для работы с протоколами, тестов и инструментов.

Файл не покидает устройство

Файл читается через FileReader, разбирается в JavaScript и возвращается как объект blob в памяти. Серверной точки загрузки не существует.

Поддерживается всё серверное ПО

NBT записывает игра, а не реализация сервера, поэтому любое ядро, которое хранит мир Minecraft, использует одно из поддерживаемых редактором кодирований. Ниже приведён полный, а не рекламный список: ядро записывает мир в формате Vanilla, потому что клиент на другом конце должен его прочитать.

Bedrock Edition — little-endian NBT, 8-байтовый заголовок level.dat

Bedrock Dedicated Server (BDS), PocketMine-MP (PM3, PM4, PM5), Nukkit, Nukkit-MOT, PowerNukkitX, Cloudburst Server, Dragonfly, Endstone, LeviLamina и BDSX, Allay, JukeboxMC, GoMint, Sculk, ElementZero, LiteLoaderBDS, а также сами клиенты MCPE и MCBE на Android, iOS, Windows, консолях и Switch. Тот же worlds/<World>/level.dat, тот же заголовок, те же теги — см. порядок работы на сервере.

Java Edition — big-endian NBT, gzip

Vanilla, CraftBukkit, Spigot, Paper, Purpur, Pufferfish, Folia, Leaves, Gale, Petal, Airplane, Sponge (SpongeVanilla, SpongeForge), Fabric, Quilt, Forge, NeoForge, Mohist, Arclight, Magma, Ketting, Banner, Cardboard, Glowstone, Thermos, Uberbukkit и любой другой форк, сервер модпака или старая сборка. Если ПО записывает world/level.dat, редактор его откроет — подробнее здесь.

Прокси и мосты

Geyser, WaterdogPE, Waterfall, Velocity и BungeeCord не хранят миры, а передают NBT по сети. Перехваченные данные этих соединений представляют собой сетевой NBT: varint little-endian со стороны Bedrock и big-endian с безымянным корнем в Java 1.20.2+. Оба варианта открываются здесь напрямую.

Всё, чего нет в списке

Пользовательские форки, закрытые ядра, учебные проекты или собственный сервер: если файл имеет формат NBT, редактор определит одно из пяти кодирований и откроет его. Логика редактора не привязана к названию ядра.

Использование парсера в своём коде

Страница предоставляет движок через window.NBT, поэтому парсер интерфейса можно вызывать из консоли браузера или использовать в пользовательском скрипте:

const bytes = new Uint8Array(await file.arrayBuffer());
const { root, format, compression, headerVersion } = await NBT.read(bytes);

root.value.find(t => t.name === "LevelName").value = "New World";

const out = await NBT.write(root, format, { compression, headerVersion });

Теги представлены обычными объектами — { type, name, value, listType }, массивы — типами Int8Array, Int32Array и BigInt64Array, а Long — типом BigInt. Полное описание формата NBT содержит сведения обо всех типах тегов и различиях кодировок.

Частые вопросы

Этот редактор NBT бесплатный?

Да, его исходный код открыт по лицензии MIT. Платного тарифа, регистрации и квоты загрузки нет, поскольку серверная часть отсутствует: весь редактор состоит из одной статической страницы и двух файлов ресурсов.

Он работает с Java Edition и Bedrock Edition?

С обоими изданиями. Файлы Java Edition имеют порядок big-endian и обычно сжаты gzip; файлы Bedrock имеют порядок little-endian, а level.dat содержит дополнительный 8-байтовый заголовок. Редактор определяет вариант и при сохранении записывает файл в том же формате.

Файл моего мира куда-нибудь загружается?

Нет. Файл читается локально через API FileReader, а загрузка создаётся из объекта blob в памяти. После открытия страницы можно отключиться от сети, и редактор продолжит работать.

Можно использовать редактор на Android или iOS?

Да. Интерфейс изначально рассчитан на мобильные устройства: зоны нажатия имеют размер 44 px, а панель действий закреплена. На Android файл мира можно выбрать в файловом менеджере; на iOS из-за изоляции приложений его сначала нужно поместить в приложение «Файлы».

Чем отличаются NBT и SNBT?

NBT — двоичное кодирование, в котором Minecraft хранит данные на диске. SNBT — его текстовая форма с синтаксисом команд вроде /data merge. Редактор читает двоичный NBT и экспортирует SNBT, чтобы сравнивать файлы или вставлять структуру в команду.

Какие инструменты заменяет этот редактор?

Настольные редакторы NBT, например NBTExplorer, и отдельные веб-инструменты, работающие только с одним изданием. В сравнении с NBTExplorer онлайн описано, какие возможности доступны и какие отсутствуют.
