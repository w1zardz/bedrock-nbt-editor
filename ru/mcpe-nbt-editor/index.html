8-байтовый заголовок и его назначение

Bedrock-файл level.dat — не обычный NBT. Первые четыре байта содержат little-endian версию хранилища (обычно 8 или 10), следующие четыре — длину данных NBT в байтах, затем идут несжатые теги. Если изменить данные и не исправить длину, игра отклонит файл. Это часто происходит при открытии сохранения Bedrock в инструменте только для Java.

СмещениеРазмерПоле
04 байтаВерсия хранилища, little-endian int
44 байтаДлина данных в байтах, беззнаковое little-endian число
8остальноеНесжатый little-endian NBT с корневым compound-тегом

Редактор показывает версию хранилища в панели файла, сохраняет её и пересчитывает длину при каждом сохранении.

Основные теги Bedrock

В Bedrock настройки находятся в корне level.dat, а не внутри compound-тега Data, как в Java. Игровые правила также хранятся отдельными тегами, а не внутри GameRules.

ТегТипЗначение
LevelNameStringНазвание мира в списке и выводе сервера
GameTypeInt0 — выживание, 1 — творчество, 2 — приключение
DifficultyIntОт 0 — мирная до 3 — сложная
commandsEnabledByteВключены или выключены читы
SpawnX, SpawnY, SpawnZIntСпавн мира
RandomSeedLongСид мира, точное 64-битное значение
lastOpenedWithVersionСписок IntПоследняя записавшая мир сборка клиента или сервера
StorageVersionIntВерсия хранилища мира, соответствующая заголовку
experimentsCompoundЭкспериментальные функции мира
keepinventory, domobspawning, …ByteИгровые правила, по одному тегу в нижнем регистре

Где найти файл на разных платформах

  • Android: Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/<id>/level.dat. Новые версии Android ограничивают доступ к папке: экспортируйте мир из игры или используйте файловый менеджер с нужными правами.
  • iOS: экспортируйте мир из игры в .mcworld, откройте его в приложении «Файлы» и распакуйте; level.dat находится в корне архива.
  • Windows: %LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\<id>\level.dat.
  • Bedrock Dedicated Server: worlds/<World>/level.dat.
  • PocketMine-MP, Nukkit, PowerNukkitX: worlds/<World>/level.dat — см. инструкцию для серверов.

Имя папки мира — случайный id, а не название. Отсортируйте папки по дате изменения либо откройте несколько файлов level.dat и найдите нужный по LevelName.

Другие файлы помимо level.dat

Bedrock хранит чанки, сущности и блочные сущности в базе LevelDB в папке db/; значения многих ключей содержат little-endian NBT. Извлечённое значение открывается как Bedrock без заголовка без заголовка и сжатия. Файлы структур используют то же кодирование: см. редактор .mcstructure. Дампы протокола используют вариант varint, определяемый как Сетевой Bedrock.

Частые вопросы

Почему level.dat Bedrock не открывается в NBTExplorer?

NBTExplorer ожидает big-endian формат Java и не учитывает 8-байтовый заголовок Bedrock. Этот редактор поддерживает оба варианта и пересчитывает длину в заголовке.

Можно изменить мир MCPE на телефоне?

Да. Откройте страницу в браузере телефона, выберите файл в файловом менеджере, измените и сохраните его. Скачанный файл появится в папке загрузок; скопируйте его поверх исходного.

Чем версии хранилища 8 и 10 отличаются?

Они обозначают версии формата хранения мира Bedrock; современные клиенты записывают 10. Редактор сохраняет исходное значение, поскольку его замена не преобразует остальные данные мира.

Поддерживаются файлы .mcworld?

Не напрямую: .mcworld — ZIP-архив. Распакуйте его, измените здесь level.dat, верните файл в архив и снова задайте расширение .mcworld.

Поддерживаются игровые правила Bedrock?

Да. Bedrock хранит каждое правило отдельным byte-тегом в нижнем регистре: keepinventory, domobspawning, showcoordinates и другие. Установите 1 или 0. Полный список есть в инструкции по игровым правилам.
