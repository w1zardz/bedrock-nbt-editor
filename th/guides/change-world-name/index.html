วิธีเปลี่ยนชื่อโลก Minecraft

รองรับ Minecraft Bedrock Edition และ Java Edition — รวมถึงซอฟต์แวร์เซิร์ฟเวอร์ทุกแบบของทั้งสองรุ่น ไม่ว่าจะเป็นที่นิยมหรือเฉพาะทาง: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina และอื่น ๆ ดูรายการทั้งหมด.

ชื่อที่แสดงของโลกอยู่ในแท็ก LevelName ภายใน level.dat ไม่ได้อยู่ที่ชื่อโฟลเดอร์ การเปลี่ยนชื่อโฟลเดอร์จึงไม่เปลี่ยนข้อความที่เกมแสดง และโลกที่คัดลอกยังคงใช้ชื่อเดิม วาง level.dat ในตัวแก้ไขด้านล่าง ระบบจะไปยัง LevelName โดยตรง จากนั้นแก้ค่า บันทึก และนำไฟล์กลับไปวาง

JavaBedrockเซิร์ฟเวอร์เล่นคนเดียว2 นาที

วาง level.dat ที่นี่

level.dat · .nbt · .mcstructure · .schem · .schematic · .dat · ข้อมูลชังก์ที่แยกออกมา

ทำไมเปลี่ยนชื่อโฟลเดอร์แล้วชื่อโลกไม่เปลี่ยน

Minecraft ใช้โฟลเดอร์เป็นที่อยู่ และใช้ LevelName เป็นชื่อที่แสดง รายการโลก คอนโซลเซิร์ฟเวอร์ ปลั๊กอินจัดการโลก และระบบที่พิมพ์ "world" ในแชตล้วนอ่านแท็กนี้ ดังนั้น cp -r worlds/hub worlds/hub2 จะสร้างโลกสองชุดที่ต่างระบุว่าชื่อ hub และต้องแก้ภายในไฟล์เท่านั้น

บนเซิร์ฟเวอร์ ชื่อซ้ำอาจทำให้ปลั๊กอินที่ค้นหาโลกตามชื่อภายในทำงานกับโลกผิดชุด เช่น จุดเทเลพอร์ต การตั้งค่ารายโลก เขตป้องกัน และตัวคูณเศรษฐกิจ จึงควรเปลี่ยนแท็กทันทีที่คัดลอกโลก ก่อนระบบใดจะบันทึกชื่อไว้ในแคช

วิธีตามแพลตฟอร์ม

Java แบบเล่นคนเดียว

ไคลเอนต์มีคำสั่งเปลี่ยนชื่อในหน้าตัวเลือกโลกและจะแก้ LevelName ให้ การแก้ไฟล์ด้วยตนเองจำเป็นเมื่อโลกโหลดไม่ได้ เมื่อทำงานกับสำเนา หรือเมื่อตั้งใจให้ชื่อโฟลเดอร์กับชื่อที่แสดงต่างกัน

เซิร์ฟเวอร์ Java

level-name ใน server.properties ใช้เลือก โฟลเดอร์ ที่จะโหลด ไม่ได้เปลี่ยนชื่อ หากต้องการเปลี่ยนชื่อที่แสดง ให้แก้ LevelName ใน world/level.dat

Bedrock และ MCPE

หน้าจอแก้ไขโลกในเกมเปลี่ยนชื่อโลกได้ หากโลกอยู่บนเซิร์ฟเวอร์หรือกำลังแก้ไฟล์ส่งออก .mcworld ให้แก้ LevelName ใน level.dat โดยตรง Bedrock เก็บแท็กนี้ที่รากแบบไม่บีบอัด หลังส่วนหัว 8 ไบต์ซึ่งตัวแก้ไขจัดการให้

เซิร์ฟเวอร์ Bedrock (PocketMine-MP, Nukkit, BDS)

ใช้ไฟล์และแท็กเดียวกัน และต้องหยุดเซิร์ฟเวอร์ก่อนเช่นกัน หน้าเซิร์ฟเวอร์ อธิบายขั้นตอนทั้งหมด รวมถึงกรณีคัดลอกโฟลเดอร์

หากชื่อไม่เปลี่ยน

  • เซิร์ฟเวอร์ยังทำงานอยู่ ข้อมูลในหน่วยความจำถูกเขียนทับไฟล์ในการบันทึกครั้งถัดไป ให้หยุดเซิร์ฟเวอร์แล้วแก้อีกครั้ง
  • คุณแก้โลกผิดชุด โฟลเดอร์โลก Bedrock ใช้ id แบบสุ่ม เปิดไฟล์และอ่าน LevelName เพื่อยืนยันก่อนแก้ไข
  • คุณแก้ level.dat_old ไฟล์นี้เป็นข้อมูลบันทึกก่อนหน้า ไม่ใช่ไฟล์ที่ใช้งานอยู่
  • launcher หรือแผงควบคุมเก็บชื่อไว้ในแคช แผงโฮสติ้งบางรายแสดงชื่อจากฐานข้อมูลของตนแทนไฟล์โลก แต่ชื่อในเกมจะถูกต้อง
  • โลกโหลดไม่ได้เลย คืนไฟล์สำรองและดู วิธีแก้ level.dat ที่เสีย

คำถามที่พบบ่อย

การเปลี่ยนชื่อโลกลบข้อมูลหรือไม่

ไม่ลบ LevelName เป็นเพียงชื่อที่แสดง ภูมิประเทศ ผู้เล่น ช่องเก็บของ และ entity อยู่ในไฟล์อื่นและจะไม่ถูกแก้ไข

ใช้ช่องว่าง สี หรืออีโมจิในชื่อโลกได้หรือไม่

ใช้ช่องว่างได้ รหัสสีแบบ section sign ใช้ได้กับซอฟต์แวร์เซิร์ฟเวอร์บางชนิด แต่อาจแสดงเป็นอักขระตรง ๆ ในระบบอื่น อีโมจิจะยังคงเดิมเพราะเครื่องมือใช้การเข้ารหัสที่ถูกต้อง แต่คอนโซลและ log อาจแสดงไม่ถูกต้อง

ต้องเปลี่ยนชื่อโฟลเดอร์ด้วยหรือไม่

ไม่ต้อง และหลายกรณีไม่ควรเปลี่ยน เพราะ level-name ของเซิร์ฟเวอร์หรือ config ปลั๊กอินอาจอ้างถึงเส้นทางโฟลเดอร์ ให้เปลี่ยนทีละอย่าง

ผู้เล่นจะเห็นชื่อใหม่ทันทีหรือไม่

เห็นหลังจากโหลดโลกใหม่ ไคลเอนต์ที่เก็บรายการเซิร์ฟเวอร์ไว้ในแคชอาจต้องรีเฟรช

เครื่องมือที่เกี่ยวข้อง

โปรแกรมแก้ไข level.datแก้ชื่อโลก โหมดเกม จุดเกิด ความยาก และกฎเกมโปรแกรมแก้ไข PocketMine-MPแก้ level.dat ฝั่งเซิร์ฟเวอร์สำหรับ PMMP, Nukkit และ BDSโปรแกรมแก้ไข NBT MCPEรองรับ NBT แบบ little-endian และส่วนหัว level.dat 8 ไบต์แก้ level.dat ที่เสียวินิจฉัยสาเหตุที่โลกโหลดไม่ได้และซ่อมไฟล์โปรแกรมแก้ไข NBT Minecraftโปรแกรมแก้ไขเดียวสำหรับทุก Edition และไฟล์ NBT ทุกชนิดแก้กฎเกมตั้ง keepInventory และกฎอื่นโดยไม่ต้องโหลดโลก
