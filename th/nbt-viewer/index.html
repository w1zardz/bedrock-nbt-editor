โปรแกรมดู NBT — เปิดไฟล์ NBT ของ Minecraft

รองรับ Minecraft Bedrock Edition และ Java Edition — รวมถึงซอฟต์แวร์เซิร์ฟเวอร์ทุกแบบของทั้งสองรุ่น ไม่ว่าจะเป็นที่นิยมหรือเฉพาะทาง: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina และอื่น ๆ ดูรายการทั้งหมด.

หากต้องการดูข้อมูลในไฟล์ Minecraft โดยไม่แก้ไข ให้วางไฟล์ .nbt, .dat, .mcstructure, .schem หรือข้อมูลดิบ NBT ด้านล่าง เพื่อดูโครงสร้างแท็กทั้งหมดพร้อมชนิดและค่า ค้นหาตามชื่อหรือค่า และส่งออกทั้งไฟล์เป็นข้อความ SNBT ไม่มีการอัปโหลดข้อมูลและไม่มีการเขียนไฟล์จนกว่าคุณจะกดบันทึก

.nbt.dat.mcstructure.schem.schematicส่งออก SNBTค้นหา

วาง ไฟล์ .nbt หรือ .dat ที่นี่

level.dat · .nbt · .mcstructure · .schem · .schematic · .dat · ข้อมูลชังก์ที่แยกออกมา

การอ่านไฟล์ที่คุณไม่ได้สร้างเอง

เหตุผลสำคัญที่ต้องเปิดไฟล์ NBT คือการวินิจฉัย เช่น ไฟล์นี้เขียนด้วยเวอร์ชันใด ทำไมโลกจึงโหลดไม่ได้ หรือ schematic ที่ได้รับมามีอะไรอยู่จริง โปรแกรมดูจะแสดงทุกแท็กพร้อมชนิดที่แน่นอน จึงแยก TAG_Byte ค่า 1 ออกจาก TAG_Int ค่า 1 ได้ ความแตกต่างนี้มีผลต่อ Minecraft และมักสูญหายเมื่อแปลงเป็นข้อความ

  • ป้ายชนิดในทุกแถว — Byte, Short, Int, Long, Float, Double, Byte[], String, List, Compound, Int[], Long[]
  • Long ขนาด 64 บิตเต็ม แสดงค่าอย่างแม่นยำ ทำให้อ่าน seed และครึ่ง UUID ได้โดยไม่ถูกปัดเศษ
  • ค้นหา ทั่วทั้งโครงสร้างตามชื่อแท็กหรือค่า และข้ามไปยังผลลัพธ์ได้ทันที
  • รูปแบบที่ตรวจพบ แสดงในแถบไฟล์ ได้แก่ Edition ลำดับไบต์ การบีบอัด และเวอร์ชันพื้นที่เก็บข้อมูล Bedrock
  • ส่งออก SNBT เพื่อรับเอกสารทั้งหมดเป็นข้อความสำหรับเปรียบเทียบ วางในคำสั่ง หรือส่งให้เครื่องมืออื่น

NBT กับ SNBT

SNBT คือรูปข้อความของ NBT ซึ่งเป็นรูปแบบที่ /data get แสดงและคำสั่งต่าง ๆ รับค่า โดยเก็บข้อมูลชนิดไว้ด้วยส่วนต่อท้าย: 3b คือ byte, 3s คือ short, 3L คือ long, 3.0f คือ float, 3.0d คือ double และ [I;1,2,3] คืออาร์เรย์ int ปุ่มส่งออกจะสร้างรูปแบบนี้โดยตรง จึงเปลี่ยนไฟล์ไบนารีเป็นข้อความที่วางใน command block หรือเก็บใน git เพื่อเปรียบเทียบทีละบรรทัดได้

JSON ใช้แทนไม่ได้ เพราะมีชนิดตัวเลขเพียงชนิดเดียวและไม่มีอาร์เรย์ byte การแปลง NBT เป็น JSON จึงทำให้ความแตกต่างที่ Minecraft ใช้สูญหายโดยไม่แจ้งเตือน เครื่องมือนี้จึงส่งออก SNBT แทน JSON

ไฟล์ที่เปิดได้ที่นี่

เปิดได้กับไฟล์ที่ภายในเป็นเอกสาร NBT เดียว ได้แก่ level.dat ของ Java และ Bedrock, playerdata, servers.dat, hotbar.nbt, idcounts.dat, raids.dat, scoreboard.dat, ข้อมูลแผนที่, โครงสร้าง .nbt, .schem และ .schematic, .mcstructure, .litematic, ข้อมูล chunk ที่แยกแล้ว และข้อมูลแพ็กเก็ต ส่วนคอนเทนเนอร์ เช่น region .mca, ไฟล์บีบอัด .mcworld และโฟลเดอร์ LevelDB ต้องแยกเอกสารหนึ่งรายการออกมาก่อน

คำถามที่พบบ่อย

ดูไฟล์ NBT โดยไม่แก้ไขได้หรือไม่

ได้ โปรแกรมจะเขียนไฟล์ก็ต่อเมื่อคุณกด Save & Download และจะไม่แก้ไขไฟล์ที่คุณวางเข้ามา

แปลง NBT เป็น JSON ได้หรือไม่

เครื่องมือส่งออก SNBT ซึ่งเก็บชนิดแท็กไว้ครบ JSON จะรวม byte, short, int, long และ float เป็นตัวเลขชนิดเดียวและทำให้อาร์เรย์ byte สูญหาย จึงไม่เหมาะกับการแปลงข้อมูล Minecraft ไปแล้วแปลงกลับ

ทำไมไฟล์จึงแสดงเป็น Edition อื่นจากที่คาดไว้

ระบบตรวจรูปแบบจากข้อมูลไบต์ ไม่ใช่นามสกุล หากรายงานเป็น Java ทั้งที่คาดว่าเป็น Bedrock มักหมายถึงไฟล์มาจากอีก Edition หรือเป็นชิ้นข้อมูลที่บังเอิญอ่านได้ หากมีคำเตือนเรื่องข้อมูลท้ายไฟล์ ให้ตรวจ offset ที่รายงาน

เปิดไฟล์ขนาดใหญ่ได้เพียงใด

เอกสารขนาดหลายเมกะไบต์ใช้งานได้ อาร์เรย์ถูกเก็บเป็น typed array และโครงสร้างจะแสดงแบบ lazy จึงสร้างบนหน้าเฉพาะแถวที่คุณขยาย

เครื่องมือที่เกี่ยวข้อง

โปรแกรมแก้ไข NBT Minecraftโปรแกรมแก้ไขเดียวสำหรับทุก Edition และไฟล์ NBT ทุกชนิดNBTExplorer ออนไลน์สิ่งที่ทำได้เหมือนเครื่องมือเดสก์ท็อปและข้อแตกต่างข้อมูลอ้างอิงรูปแบบ NBTแท็กทั้ง 13 ชนิดและการเข้ารหัสทุกแบบ อธิบายทีละไบต์โปรแกรมแก้ไข Schematicรองรับ WorldEdit .schem และ MCEdit .schematic แบบเก่าโปรแกรมแก้ไข .mcstructureแก้พาเลต ขนาด และ block entity ของ Structure Blockโปรแกรมแก้ไข playerdataแก้ช่องเก็บของ ตำแหน่ง พลังชีวิต และสถิติของผู้เล่น
