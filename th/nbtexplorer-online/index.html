โปรแกรมแก้ไข NBT / NBTExplorer ออนไลน์

NBTExplorer ออนไลน์ — ทางเลือกบนเบราว์เซอร์

รองรับ Minecraft Bedrock Edition และ Java Edition — รวมถึงซอฟต์แวร์เซิร์ฟเวอร์ทุกแบบของทั้งสองรุ่น ไม่ว่าจะเป็นที่นิยมหรือเฉพาะทาง: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina และอื่น ๆ ดูรายการทั้งหมด.

NBTExplorer เป็นเครื่องมือแก้แท็กบนเดสก์ท็อปที่ผู้เล่น Minecraft รู้จักกันดี และต้องใช้ .NET หรือ Mono พร้อมดาวน์โหลดโปรแกรม หน้านี้ทำงานเดียวกันได้ ทั้งดูโครงสร้างแท็ก แก้ค่าในบรรทัด เพิ่มและลบแท็ก ผ่านเบราว์เซอร์บนทุกระบบรวมถึงโทรศัพท์ และยังอ่านไฟล์ little-endian ของ Bedrock ซึ่ง NBTExplorer ไม่รองรับ

หากต้องการเปิดทั้งโฟลเดอร์ region และเลือก chunk ตามพิกัด เครื่องมือเดสก์ท็อปยังเหมาะกว่า หากต้องเปิดไฟล์เดียว เช่น level.dat ไฟล์ผู้เล่น schematic หรือโลก Bedrock บนอุปกรณ์ที่กำลังใช้ หน้านี้ทำงานได้เร็วกว่าและรองรับ Edition ที่เครื่องมือเดสก์ท็อปไม่รองรับ

สำหรับผู้ที่ย้ายมาจากเครื่องมือเดสก์ท็อป

  • โครงสร้างต้นไม้ทำงานเหมือนกัน ขยาย Compound และลิสต์ คลิกค่าเพื่อแก้ไข และใช้ + กับ × เพื่อปรับโครงสร้าง
  • มีการบังคับชนิดข้อมูลเหมือนกัน byte ยังคงเป็น byte และค่าที่เกินช่วงจะถูกปฏิเสธแทนการตัดค่าโดยไม่แจ้ง
  • การบันทึกเป็นการดาวน์โหลด ไม่ได้เขียนทับไฟล์เดิม ไฟล์ที่วางเข้ามาจะไม่ถูกแก้ไข จึงมีต้นฉบับสำรองโดยอัตโนมัติ
  • คงรูปแบบการบีบอัด ไฟล์ gzip จะถูกส่งออกเป็น gzip เกมจึงอ่านได้โดยไม่ต้องบีบอัดใหม่ด้วยตนเอง
  • Bedrock ใช้งานได้โดยตรง ไม่ต้องใช้เครื่องมือแยกหรือใช้โปรแกรมแก้ hex เพื่อแก้ความยาวส่วนหัวหลังแก้ไข

งานที่ยังเหมาะกับเครื่องมืออื่น

ใช้ NBTExplorer หรือ NBTStudio เมื่อต้องเปิดดู region จำนวนมาก ใช้ Amulet หรือ MCA Selector เมื่อต้องแก้ไขระดับ chunk หรือตัดส่วนของโลก ใช้ WorldEdit กับงานด้านรูปทรง และใช้หน้านี้เมื่องานคือ “เปิดไฟล์เดียว แก้แท็กเหล่านี้ แล้วส่งไฟล์กลับ” ซึ่งครอบคลุมงานส่วนใหญ่ หรือเมื่อเป็นไฟล์ Bedrock ที่เครื่องมือเดสก์ท็อปเปิดไม่ได้

คำถามที่พบบ่อย

มี NBTExplorer เวอร์ชันเว็บอย่างเป็นทางการหรือไม่

ไม่มี NBTExplorer เป็นแอปพลิเคชันเดสก์ท็อป ส่วนเครื่องมือนี้เป็นตัวแก้ไขอิสระที่ทำงานทั่วไปแบบเดียวกันในเบราว์เซอร์และเพิ่มการรองรับ Bedrock

ใช้บน macOS และ Linux โดยไม่ติดตั้ง Mono ได้หรือไม่

ได้ เพราะเป็นหน้าเว็บ เบราว์เซอร์รุ่นปัจจุบันบน macOS, Linux, Windows, Android หรือ ChromeOS ใช้งานได้

เปิดไฟล์ region ทั้งไฟล์เหมือน NBTExplorer ได้หรือไม่

ไม่ได้ เครื่องมือนี้แก้เอกสาร NBT ครั้งละหนึ่งรายการ ต้องแยก chunk จาก .mca ก่อน แล้วจึงวางข้อมูลที่นี่

ใช้กับไฟล์บันทึกเพียงชุดเดียวปลอดภัยหรือไม่

เครื่องมือจะไม่เขียนทับไฟล์ที่เปิด การแก้ไขจะส่งกลับเป็นไฟล์ดาวน์โหลดใหม่ แต่ควรเก็บข้อมูลสำรองของคุณเองเช่นเดียวกับการใช้เครื่องมือแก้ไขทุกชนิด

เครื่องมือที่เกี่ยวข้อง

โปรแกรมแก้ไข NBT Minecraftโปรแกรมแก้ไขเดียวสำหรับทุก Edition และไฟล์ NBT ทุกชนิดโปรแกรมดู NBTตรวจสอบแบบอ่านอย่างเดียว ค้นหา และส่งออก SNBTโปรแกรมแก้ไข NBT Java Editionรองรับ big-endian และ gzip จาก Vanilla, Paper, Spigot, Fabric, Forgeโปรแกรมแก้ไข NBT MCPEรองรับ NBT แบบ little-endian และส่วนหัว level.dat 8 ไบต์ข้อมูลอ้างอิงรูปแบบ NBTแท็กทั้ง 13 ชนิดและการเข้ารหัสทุกแบบ อธิบายทีละไบต์โปรแกรมแก้ไข level.datแก้ชื่อโลก โหมดเกม จุดเกิด ความยาก และกฎเกม
