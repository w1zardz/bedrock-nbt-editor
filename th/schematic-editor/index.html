โปรแกรมแก้ไข NBT / .schem

โปรแกรมแก้ไข Schematic .schem และ .schematic ออนไลน์

รองรับ Minecraft Bedrock Edition และ Java Edition — รวมถึงซอฟต์แวร์เซิร์ฟเวอร์ทุกแบบของทั้งสองรุ่น ไม่ว่าจะเป็นที่นิยมหรือเฉพาะทาง: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina และอื่น ๆ ดูรายการทั้งหมด.

Schematic เป็น NBT แบบ big-endian ที่บีบอัดด้วย gzip วางไฟล์ WorldEdit รุ่นใหม่ .schem (รูปแบบ Sponge Schematic) หรือไฟล์ MCEdit รุ่นเก่า .schematic ด้านล่างเพื่อตรวจพาเลต ขนาด ออฟเซ็ต รายการ block entity และ metadata แก้แท็กใดก็ได้แล้วดาวน์โหลดไฟล์กลับพร้อมใช้กับ //paste.

วาง ไฟล์ .schem หรือ .schematic ที่นี่

สองรูปแบบในกลุ่มนามสกุลไฟล์เดียว

รูปแบบนามสกุลแท็กหลัก
Sponge Schematic v2 (WorldEdit 7).schemVersion, DataVersion, Width, Height, Length, Palette, BlockData, BlockEntities, Offset, Metadata
Sponge Schematic v3.schemข้อมูลเดียวกันซ้อนอยู่ใต้ Schematic compound โดย Blocks เก็บ Palette และ Data
MCEdit รุ่นเก่า.schematicWidth, Height, Length, Blocks, Data, Entities, TileEntities, Materials

BlockData ในรูปแบบ Sponge เป็นอาร์เรย์ไบต์ของดัชนีพาเลตแบบ varint ไม่ใช่หนึ่งไบต์ต่อบล็อก id ที่ยาวจะต่อเนื่องหลายไบต์ ส่วนรูปแบบเก่าเก็บ id บล็อกแบบตัวเลขดิบใน Blocks พร้อมอาร์เรย์ Data ของ metadata nibble ที่ตำแหน่งตรงกัน จึงทำให้ schematic เก่าสูญเสียข้อมูลบางส่วนในเวอร์ชันใหม่

ค่าที่เหมาะกับการแก้ด้วยมือ

  • รายการพาเลต การเปลี่ยน minecraft:oak_planks เป็น minecraft:spruce_planks ใน Palette จะเปลี่ยนบล็อกที่ตรงกันทั้งหมดใน schematic พร้อมกัน
  • ออฟเซ็ตและจุดกำเนิด Offset กำหนดตำแหน่งวางเมื่อเทียบกับตำแหน่งของคุณ จึงใช้แก้งานสร้างที่วางคลาดไปหลายบล็อกได้รวดเร็ว
  • Block entity ของในหีบ บรรทัดข้อความบนป้าย และข้อมูล spawner อยู่ใน BlockEntities และลบข้อมูลที่ไม่ต้องการได้ก่อนแชร์สิ่งปลูกสร้าง
  • Metadata Metadata เก็บชื่อผู้สร้างและจุดกำเนิด WorldEdit แก้ไขได้โดยไม่กระทบโครงสร้าง และมักล้างก่อนเผยแพร่
  • DataVersion ระบุเวอร์ชัน Minecraft ที่สร้าง schematic ซึ่งช่วยอธิบายข้อผิดพลาด "unknown block" ส่วนใหญ่เมื่อวาง

ความเข้ากันได้กับตัวโหลด

WorldEdit และ FastAsyncWorldEdit อ่านไฟล์ .schem จาก plugins/WorldEdit/schematics/ ส่วนไฟล์เก่า .schematic ยังโหลดได้ แต่จะถูกแปลงระหว่างนำเข้า Litematica ใช้คอนเทนเนอร์ .litematic ของตน ซึ่งเป็น NBT และเปิดในโปรแกรมนี้ได้ แม้โครงสร้างจะต่างจาก Sponge ไม่ว่ารูปแบบใด โปรแกรมจะอ่านเป็น NBT และเขียนกลับพร้อมบีบอัด gzip เพื่อให้ตัวโหลดได้รับรูปแบบที่ต้องการ

คำถามที่พบบ่อย

เปิด .schem โดยไม่มีเซิร์ฟเวอร์หรือ WorldEdit ได้หรือไม่?

ได้ ไฟล์ .schem เป็นเพียง NBT แบบ big-endian ที่บีบอัด gzip โปรแกรมเปิดในเบราว์เซอร์ได้โดยไม่ต้องติดตั้งอย่างอื่น

ทำไม schematic จึงวางออกมาเป็นบล็อกผิด?

โดยทั่วไปเกิดจากเวอร์ชันไม่ตรงกัน ให้ตรวจ DataVersion และพาเลต schematic ที่ส่งออกจากเวอร์ชันใหม่อาจอ้างสถานะบล็อกที่เซิร์ฟเวอร์เก่าไม่รู้จัก

เปลี่ยนขนาด schematic ที่นี่ได้หรือไม่?

แก้เพียง Width/Height/Length อย่างเดียวไม่ได้ BlockData มีขนาดตามปริมาตร จึงต้องเปลี่ยนทั้งมิติและข้อมูลพร้อมกัน งานนี้ควรทำด้วย WorldEdit ไม่ใช่โปรแกรมแก้แท็ก

เปิดไฟล์ .litematic ได้หรือไม่?

เปิดได้ในฐานะ NBT โครงสร้างแท็กของ Litematica ต่างจาก Sponge จึงแสดงโครงสร้างดั้งเดิมของไฟล์แทนพาเลต schematic

เครื่องมือที่เกี่ยวข้อง

โปรแกรมแก้ไข NBT Java Editionรองรับ big-endian และ gzip จาก Vanilla, Paper, Spigot, Fabric, Forgeโปรแกรมแก้ไข .mcstructureแก้พาเลต ขนาด และ block entity ของ Structure Blockโปรแกรมแก้ไข NBT Minecraftโปรแกรมแก้ไขเดียวสำหรับทุก Edition และไฟล์ NBT ทุกชนิดข้อมูลอ้างอิงรูปแบบ NBTแท็กทั้ง 13 ชนิดและการเข้ารหัสทุกแบบ อธิบายทีละไบต์โปรแกรมดู NBTตรวจสอบแบบอ่านอย่างเดียว ค้นหา และส่งออก SNBTโปรแกรมแก้ไข level.datแก้ชื่อโลก โหมดเกม จุดเกิด ความยาก และกฎเกม
