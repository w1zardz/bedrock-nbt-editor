.mcstructure 편집기 — Bedrock 구조물 파일

Minecraft Bedrock Edition과 Java Edition을 지원합니다. Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina 등 유명하거나 잘 알려지지 않은 양쪽 에디션의 모든 서버 코어를 지원합니다. 전체 목록

.mcstructure 파일은 Bedrock 구조물 블록이 기록하는 압축되지 않은 리틀 엔디언 NBT입니다. 아래에 파일을 놓으면 크기, 블록 팔레트, 블록 인덱스, 블록 엔티티 데이터를 읽고 수정한 뒤 같은 인코딩으로 다시 다운로드할 수 있습니다. 월드를 다시 열지 않고 구조물을 손봐야 하는 애드온 및 맵 제작자에게 유용합니다.

.mcstructure 내부 구조

태그유형저장 내용
format_versionInt구조물 형식 리비전이며 현재 파일은 1
sizeInt 목록캡처한 영역의 X, Y, Z 크기
structure_world_originInt 목록월드에서 구조물을 캡처한 위치
structureCompound아래의 모든 항목이 들어가는 위치
structure.block_indicesInt[] 목록팔레트 인덱스 두 레이어로, 보통 블록과 물 채움을 나타냅니다. -1은 "현재 상태 유지"를 뜻합니다.
structure.entitiesCompound 목록구조물과 함께 캡처된 엔티티
structure.palette.default.block_paletteCompound 목록name, states, version으로 구성된 모든 고유 블록 상태
structure.palette.default.block_position_dataCompound위치의 평면 인덱스를 키로 사용하는 블록 엔티티 NBT

block_indices의 인덱스는 X, Z, Y 순서로 진행합니다. 팔레트 목록을 가리키는 평면 인덱스 공식은 (x * sizeZ + z) * sizeY + y입니다. 이 대응 관계를 이용하면 구조물을 다시 생성하지 않고도 잘못 설정된 블록 하나를 고칠 수 있습니다.

자주 수정하는 항목

  • 모든 위치의 블록 유형 바꾸기: block_palette 항목 하나를 수정하면 해당 인덱스를 가리키는 모든 위치가 함께 바뀝니다.
  • 블록 상태 고치기: facing compound에서 잘못된 waterlogged이나 의도치 않은 states를 수정합니다.
  • 엔티티 제거하기: 실수로 포함된 엔티티를 entities 목록에서 삭제합니다.
  • 블록 엔티티 데이터 복구하기: block_position_data에서 상자 내용물, 표지판 텍스트, 스포너 설정을 고칩니다.
  • 버전 스탬프 확인하기: 게임 업데이트 뒤 구조물을 가져올 때 잘못된 블록이 나오면 팔레트 항목의 버전을 확인합니다.

파일 위치

구조물 블록은 월드 디렉터리 안의 structures/ 폴더에 <namespace>_<name>.mcstructure 이름으로 저장합니다. 행동 팩은 팩 안의 structures/에 파일을 넣고 게임이 네임스페이스로 불러옵니다. 둘 다 같은 형식이며 여기서 열 수 있습니다.

Java Edition에 대응하는 파일은 gzip 빅 엔디언 .nbt 구조물 파일로, 인코딩과 태그 구조가 다릅니다. Java 편집기 페이지에서 자세히 설명하며 이 편집기로도 열 수 있습니다.

자주 묻는 질문

.mcstructure를 Java .nbt 구조물로 변환할 수 있나요?

바이트를 빅 엔디언 gzip으로 다시 인코딩할 수는 있지만 태그 구조가 다릅니다. Java 구조물은 다른 키와 블록 이름을 가진 palette/blocks를 사용합니다. 재인코딩한 파일은 읽을 수 있어도 유효한 Java 구조물은 아닙니다.

.mcstructure가 압축되지 않은 이유는 무엇인가요?

Bedrock은 구조물 파일을 gzip 래퍼가 없는 원시 리틀 엔디언 NBT로 기록합니다. 정상적인 형식이며 편집기에는 Bedrock 원시 형식으로 표시됩니다.

block_indices에서 -1 인덱스는 무엇을 뜻하나요?

구조물이 건드리지 않는 위치를 나타냅니다. 구조물을 배치할 때 월드의 기존 블록이 그대로 유지됩니다.

size를 수정해 구조물 크기를 바꿀 수 있나요?

size만 바꿔서는 안 됩니다. block_indices에는 위치마다 항목 하나가 있으므로 배열 길이가 새 부피와 정확히 일치해야 합니다. size만 바꾸면 게임이 파일을 거부합니다.
