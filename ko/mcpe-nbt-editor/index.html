8바이트 헤더가 중요한 이유

Bedrock level.dat는 원시 NBT가 아닙니다. 처음 4바이트는 리틀 엔디언 저장소 버전이며 실제 파일에서는 8과 10이 쓰입니다. 다음 4바이트는 NBT 페이로드의 바이트 길이이고, 그 뒤에 압축되지 않은 태그가 옵니다. 페이로드를 수정한 뒤 길이를 고치지 않으면 게임이 파일을 거부합니다. Bedrock 저장 파일을 Java 전용 NBT 도구에서 열 때 바로 이 문제가 생깁니다.

오프셋크기필드
04바이트저장소 버전, 리틀 엔디언 int
44바이트바이트 단위 페이로드 길이, 리틀 엔디언 unsigned
8나머지리틀 엔디언 NBT, 루트 compound, 압축 안 함

이 편집기는 파일 표시줄에 저장소 버전을 보여주고 그대로 보존하며, 저장할 때마다 길이를 자동으로 다시 기록합니다.

알아두면 좋은 Bedrock 태그

Bedrock은 Java처럼 설정을 level.dat compound 아래에 넣지 않고 Data 루트에 평면적으로 보관합니다. 게임 규칙도 GameRules 하위 항목이 아니라 각각의 태그입니다.

태그유형의미
LevelNameString월드 목록과 서버 출력에 표시되는 월드 이름
GameTypeInt0 서바이벌, 1 크리에이티브, 2 어드벤처
DifficultyInt0 평화로움 … 3 어려움

SpawnX, SpawnY, SpawnZInt월드 스폰

플랫폼별 파일 찾기

  • Android: Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/<id>/level.dat. 최신 Android 버전은 이 폴더 접근을 제한합니다. 게임 내 월드 내보내기를 사용하거나 적절한 권한이 있는 파일 관리자를 쓰세요.
  • iOS: 게임에서 월드를 .mcworld로 내보낸 뒤 파일 앱에서 열고 압축을 푸세요. level.dat는 압축 파일 루트에 있습니다.
  • Windows: %LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\<id>\level.dat.
  • Bedrock Dedicated Server: worlds/<World>/level.dat.
  • PocketMine-MP, Nukkit, PowerNukkitX: worlds/<World>/level.dat. 서버 측 안내도 참고하세요.

월드 폴더 이름은 월드 이름이 아니라 임의 ID입니다. 수정 시간순으로 정렬하거나, 여러 level.dat를 여기서 열어 LevelName을 확인하면 원하는 월드를 찾을 수 있습니다.

level.dat 이외의 파일

Bedrock은 청크, 엔티티, 블록 엔티티를 db/ 폴더의 LevelDB 데이터베이스에 저장하며, 많은 키의 값으로 리틀 엔디언 NBT를 씁니다. 값을 추출하면 헤더와 압축이 없는 Bedrock 원시 형식으로 여기서 열립니다. 구조물 파일도 같은 인코딩을 사용합니다. .mcstructure 편집기를 참고하세요. 프로토콜 캡처는 varint 변형을 쓰며 편집기가 Bedrock 네트워크로 감지합니다.

자주 묻는 질문

Bedrock level.dat가 NBTExplorer에서 열리지 않는 이유는 무엇인가요?

NBTExplorer는 Java의 빅 엔디언 구조를 기대하며 8바이트 Bedrock 헤더를 인식하지 못하기 때문입니다. 이 편집기는 두 형식을 모두 처리하고 저장할 때 헤더의 길이도 다시 기록합니다.

휴대전화에서 MCPE 월드를 편집할 수 있나요?

네. 휴대전화 브라우저에서 이 페이지를 열고 파일 관리자에서 파일을 선택해 수정한 뒤 저장하세요. 다운로드 폴더에 저장된 파일을 원본 위치에 덮어쓰면 됩니다.

저장소 버전 8과 10은 무엇이 다른가요?

Bedrock 월드 저장 형식의 리비전을 나타내며 현재 클라이언트는 10을 기록합니다. 편집기는 특정 값으로 강제하지 않고 원본 값을 유지합니다. 이 값만 바꿔도 뒤에 있는 월드 데이터가 마이그레이션되지는 않기 때문입니다.

.mcworld 파일도 처리하나요?

직접 열 수는 없습니다. .mcworld는 zip 압축 파일입니다. 압축을 풀고 여기서 level.dat를 수정한 다음 압축 파일에 다시 넣고 확장자를 .mcworld로 바꾸세요.

Bedrock 게임 규칙도 수정할 수 있나요?

네. Bedrock은 각 규칙을 루트에 소문자 byte 태그로 저장합니다. keepinventory, domobspawning, showcoordinates 등이 있으며 byte 값을 1 또는 0으로 설정합니다. 게임 규칙 안내에서 목록을 확인하세요.
