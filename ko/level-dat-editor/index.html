level.dat 편집기 — Minecraft 월드 설정을 온라인에서 변경

Minecraft Bedrock Edition과 Java Edition을 지원합니다. Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina 등 유명하거나 잘 알려지지 않은 양쪽 에디션의 모든 서버 코어를 지원합니다. 전체 목록

level.dat는 Minecraft 월드 자체의 모든 정보를 담는 파일입니다. 월드 이름, 게임 모드, 난이도, 스폰 지점, 게임 규칙, 날씨 상태, 마지막으로 연 Minecraft 버전이 여기에 저장됩니다. 아래에 파일을 놓으면 값을 직접 수정할 수 있습니다. Java 파일(gzip, 빅 엔디언)과 Bedrock 파일(8바이트 헤더가 있는 리틀 엔디언)을 모두 처리하며, 받은 형식 그대로 다시 기록합니다.

실제로 자주 수정하는 태그

Java level.dat는 거의 모든 내용을 하나의 Data compound 안에 보관하고, Bedrock level.dat는 루트에 태그를 평면적으로 둡니다. 아래 이름만 알아두면 됩니다. 트리에서 검색하면 편집기가 해당 태그로 이동합니다.

태그유형에디션제어 항목
LevelNameString모두월드에 표시되는 이름입니다. 월드 폴더를 복사하면 이전 이름이 남습니다. 이름 변경 안내에서 해결 방법을 설명합니다.
GameType / gameTypeInt모두0 서바이벌, 1 크리에이티브, 2 어드벤처, 3 관전자입니다.
DifficultyByte / Int모두0 평화로움, 1 쉬움, 2 보통, 3 어려움입니다.
hardcoreByte모두1이면 월드가 하드코어 규칙으로 고정됩니다.
allowCommands / commandsEnabledByteJava / Bedrock치트 사용 여부를 정합니다.
SpawnX, SpawnY, SpawnZInt모두월드 스폰 좌표입니다.
Time, DayTimeLongJava총 틱 수와 현재 시각입니다.
currentTickIntBedrockBedrock에서 월드 시계에 해당하는 값입니다.
RandomSeed / WorldGenSettings.seedLongJava월드 시드입니다. 반올림되는 double이 아니라 실제 64비트 값으로 유지합니다.
GameRules / 개별 gamerule 태그Compound / ByteJava / Bedrock/gamerule로 설정하는 모든 항목입니다. 게임 규칙 안내를 참고하세요.
DataVersionIntJava월드 형식 버전입니다. 서로 다른 Minecraft 버전 사이로 월드를 옮기기 전에 확인하세요.
lastOpenedWithVersionInt 목록Bedrock월드를 마지막으로 기록한 Bedrock 클라이언트 또는 서버 빌드입니다.
PlayerCompound모두월드 파일에 포함된 싱글 플레이어 인벤토리, 위치, 통계입니다.

Minecraft는 같은 위치에 이전 저장본인 level.dat_old도 기록합니다. 이 편집기에서 해당 파일도 열 수 있습니다. 현재 파일이 불러와지지 않을 때 가장 먼저 확인해 보세요.

안전하게 편집하기

  • 먼저 서버를 중지하거나 게임을 종료하세요. Minecraft는 자동 저장과 종료 시 level.dat를 다시 기록합니다. 서버가 실행 중이면 수정 사항을 덮어쓸 수 있으며, 복사가 덜 된 파일 위에 기록할 수도 있습니다.
  • 원본을 보관하세요. 이 편집기는 가져온 파일을 직접 수정하지 않고 새 다운로드 파일을 만듭니다. 월드가 한 번 정상적으로 불러와질 때까지 원본을 보관하세요.
  • 태그 유형을 바꾸지 마세요. Difficulty를 Byte에서 Int로 바꾸거나 Minecraft가 요구하는 태그 이름을 변경하면 월드가 불러와지지 않을 수 있습니다. 이유를 정확히 아는 경우가 아니라면 구조 대신 값만 수정하세요.
  • Bedrock 헤더를 유지하세요. 8바이트 헤더에는 저장소 버전과 페이로드 길이가 들어 있습니다. 편집기는 길이를 자동으로 다시 쓰고 버전을 보존합니다. 수동 편집으로 헤더가 사라진 파일은 불러올 수 없습니다.

자주 묻는 질문

프로그램을 다운로드하지 않고 level.dat를 편집할 수 있나요?

네. 바로 이 페이지에서 할 수 있습니다. 파서가 브라우저에서 실행되므로 설치할 것이 없으며 최신 브라우저만 있으면 운영체제와 관계없이 사용할 수 있습니다.

월드에 예전 이름이 계속 표시되는 이유는 무엇인가요?

월드 목록의 이름은 폴더명이 아니라 LevelName 안의 level.dat에서 가져오기 때문입니다. 폴더를 복사하거나 이름을 바꿔도 태그는 그대로입니다. 해당 태그를 수정하면 목록도 바뀝니다.

level.dat_old도 편집할 수 있나요?

네. level.dat_old는 같은 형식으로 저장된 이전 저장본입니다. 현재 파일이 손상되었다면 _old 사본을 열어 내용이 정상인지 확인한 뒤 원래 파일명으로 복원하세요.

여기서 월드 시드를 바꿀 수 있나요?

시드 태그를 수정할 수 있지만 변경 후 새로 생성되는 지형에만 적용됩니다. 디스크에 이미 저장된 청크는 기존 시드로 생성된 모양을 유지하므로 이전 지형과 새 지형의 경계가 눈에 띌 수 있습니다.

level.dat를 수정하면 차단되거나 월드가 손상되나요?

자신의 저장 파일이므로 차단될 일은 없습니다. 월드 손상은 주로 서버가 실행 중일 때 편집하거나 값이 아닌 태그 유형과 이름을 바꿀 때 생깁니다. 서버를 중지하고 값만 수정하며 백업을 보관하세요.
