온라인 NBTExplorer — 브라우저 대안

Minecraft Bedrock Edition과 Java Edition을 지원합니다. Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina 등 유명하거나 잘 알려지지 않은 양쪽 에디션의 모든 서버 코어를 지원합니다. 전체 목록

NBTExplorer는 많은 Minecraft 플레이어가 아는 데스크톱 태그 편집기이며 .NET 또는 Mono와 프로그램 다운로드, 데스크톱 환경이 필요합니다. 이 페이지는 태그 트리, 인라인 편집, 태그 추가 및 제거 기능을 모든 운영체제와 휴대전화의 브라우저에서 제공합니다. NBTExplorer가 처리하지 못하는 Bedrock 리틀 엔디언 파일도 읽습니다.

Region 폴더 전체를 탐색하며 좌표로 청크를 열어야 한다면 데스크톱 도구가 더 낫습니다. level.dat, 플레이어 파일, schematic, Bedrock 월드처럼 파일 하나를 현재 사용 중인 기기에서 열려면 이 도구가 더 빠르고 데스크톱 도구가 지원하지 않는 에디션까지 처리합니다.

데스크톱 도구에서 옮겨오기

  • 트리 사용 방식은 같습니다. compound와 list를 펼치고 값을 눌러 수정하며 +와 ×로 구조를 바꿉니다.
  • 유형도 같은 방식으로 제한합니다. byte는 byte로 유지하며 범위를 벗어난 값은 조용히 잘라내지 않고 거부합니다.
  • 저장은 원본 직접 기록이 아니라 다운로드입니다. 가져온 파일을 수정하지 않으므로 원본이 자동으로 백업 역할을 합니다.
  • 압축 방식도 그대로 유지합니다. gzip 파일은 다시 gzip으로 나오므로 수동 재압축 없이 게임에서 인식합니다.
  • Bedrock도 바로 작동합니다. 별도 도구나 수정 뒤 헤더 길이를 고칠 hex 편집기가 필요 없습니다.

다른 도구가 더 알맞은 작업

Region을 대량으로 탐색하려면 NBTExplorer 또는 NBTStudio를 사용하세요. 청크 단위 복구와 월드 정리에는 Amulet이나 MCA Selector가 알맞고, 형태를 바꾸는 작업에는 WorldEdit을 쓰세요. 이 페이지는 "파일 하나를 열고 태그를 바꾼 뒤 다시 받기"가 목적일 때, 또는 Bedrock 파일을 데스크톱 도구에서 거부할 때 사용하면 됩니다.

자주 묻는 질문

공식 NBTExplorer 웹 버전이 있나요?

아니요. NBTExplorer는 데스크톱 애플리케이션입니다. 이 도구는 일상적인 같은 작업을 브라우저에서 처리하고 Bedrock 지원을 추가한 독립 편집기입니다.

Mono 없이 macOS와 Linux에서 작동하나요?

네. 웹 페이지이므로 macOS, Linux, Windows, Android, ChromeOS의 최신 브라우저에서 실행됩니다.

NBTExplorer처럼 Region 파일 전체를 열 수 있나요?

아니요. 한 번에 NBT 문서 하나를 편집합니다. 먼저 .mca에서 청크를 추출한 뒤 페이로드를 여기에 놓으세요.

저장 파일이 하나뿐이어도 안전한가요?

연 파일에 직접 쓰지 않고 수정본을 새로 다운로드합니다. 그래도 다른 편집기를 사용할 때처럼 별도의 백업을 보관하세요.
