PocketMine-MP 및 Bedrock 서버 level.dat 편집기

Minecraft Bedrock Edition과 Java Edition을 지원합니다. Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina 등 유명하거나 잘 알려지지 않은 양쪽 에디션의 모든 서버 코어를 지원합니다. 전체 목록

PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, 공식 Bedrock Dedicated Server는 모두 level.dat에 있는 8바이트 헤더의 리틀 엔디언 worlds/<World>/를 읽습니다. 아래에 파일을 놓아 월드 폴더를 복제한 뒤 이름을 고치고, 스폰을 옮기고, 게임 규칙을 바꾸거나 마지막으로 월드를 기록한 빌드를 확인하세요.

복제된 월드 이름 문제

Bedrock 서버 관리자는 흔히 이 문제를 겪습니다. 두 번째 아레나를 만들려고 worlds/hub을 worlds/hub2로 복사해도 콘솔, 월드 관리자, 월드 이름을 표시하는 모든 플러그인이 두 월드를 모두 hub이라고 부릅니다. 폴더 이름만 바뀌었고 LevelName 안의 level.dat은 그대로이기 때문입니다.

단순히 표시만 잘못되는 문제가 아닙니다. 텔레포트 패드, 월드별 설정, 지역 보호처럼 내부 이름으로 월드를 찾는 플러그인이 엉뚱한 월드를 선택할 수 있고 월드 관리 명령도 모호해집니다. 위에 파일을 놓으면 편집기가 LevelName으로 바로 이동해 편집 창을 엽니다.

  1. 서버를 중지합니다. 실행 중인 서버는 저장할 때 level.dat를 다시 기록해 수정 사항을 되돌립니다.
  2. SFTP 또는 패널의 파일 관리자에서 worlds/<World>/level.dat를 다운로드합니다.
  3. 편집기에 파일을 놓고 LevelName을 새 이름으로 바꾼 뒤 저장합니다.
  4. 기존 파일을 백업으로 남기고 새 파일을 원본 위치에 업로드합니다.
  5. 서버를 시작하고 불러온 월드를 알리는 콘솔 줄을 확인합니다.

코어별 참고 사항

코어월드 경로참고
PocketMine-MP (PM5)worlds/<World>/기본 월드는 level-name의 server.properties으로 정합니다. 이 값은 폴더를 가리키며 LevelName은 월드 자체의 이름입니다.
Nukkit / PowerNukkitXworlds/<World>/같은 Bedrock 구조를 사용하며 PNX는 옆에 자체 설정 파일을 추가합니다.
Bedrock Dedicated Serverworlds/<World>/level-name의 server.properties으로 폴더를 고릅니다. 헤더의 저장소 버전은 보통 10입니다.
Cloudburst / Dragonflyworlds/<World>/같은 level.dat를 읽습니다. Dragonfly는 자체 데이터베이스에 추가 상태를 저장할 수 있습니다.
WaterdogPE, Geyser—프록시이므로 월드를 직접 보유하지 않습니다. NBT는 네트워크 NBT로 통과할 뿐입니다.

운영 서버를 손상시키지 않는 방법

  • 월드 폴더 전체를 백업하세요. level.dat만 백업해서는 안 됩니다. 몇 초면 끝나며 잘못된 수정을 되돌릴 수 있는 유일한 방법입니다.
  • 실행 중인 파일을 SFTP로 직접 편집하지 마세요. 서버를 중지한 상태에서 다운로드하고 수정한 뒤 업로드하세요. 서버가 월드를 연 상태에서 직접 편집하면 파일이 잘릴 수 있습니다.
  • 새 모드를 만들기 위해 월드를 복사하나요? 서버가 월드를 보기 전에 복사 직후 LevelName을 바꾸세요. 그러면 잘못된 이름이 캐시에 들어가지 않습니다.
  • 파일을 불러온 뒤 파일 표시줄을 확인하세요. 감지된 형식과 저장소 버전이 표시됩니다. Bedrock 파일이 Bedrock level.dat 이외의 형식으로 나타나면 잘못된 파일을 가져왔거나 파일이 손상된 것입니다.

자주 묻는 질문

PocketMine-MP는 Bedrock과 같은 level.dat를 사용하나요?

네. PocketMine-MP는 Bedrock 월드 형식을 구현하므로 level.dat는 8바이트 헤더가 있는 리틀 엔디언 NBT입니다. Vanilla Bedrock 서버가 기록하는 파일과 바이트 구조가 같습니다.

콘솔에서 두 월드의 이름이 같은 이유는 무엇인가요?

두 폴더를 하나에서 복사해 같은 LevelName을 공유하기 때문입니다. 폴더명과 태그는 서로 독립적이므로 태그를 바꾸세요.

서버를 다시 시작하지 않고 월드 이름을 바꿀 수 있나요?

아니요. 월드는 메모리에 불러와져 있으며 저장할 때 다시 기록되므로 실행 중에 수정한 파일은 폐기됩니다. 서버를 중지하고 편집한 뒤 다시 시작하세요.

Nukkit과 PowerNukkitX에서도 작동하나요?

네. 형식과 파일 경로, 작업 절차가 모두 같습니다.

Bedrock 월드를 Java로 어떻게 변환하나요?

NBT 편집기로는 할 수 없습니다. 바이트 순서는 쉬운 부분일 뿐이며 태그 구조, 블록 팔레트, 청크 저장 방식이 완전히 다릅니다. 전용 변환기를 사용한 뒤 남은 메타데이터를 이 편집기로 수정하세요.
