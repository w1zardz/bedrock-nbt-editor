Minecraft 월드 이름 변경 방법

Minecraft Bedrock Edition과 Java Edition을 지원합니다. Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina 등 유명하거나 잘 알려지지 않은 양쪽 에디션의 모든 서버 코어를 지원합니다. 전체 목록

월드의 표시 이름은 폴더명이 아니라 LevelName 안의 level.dat 태그에 있습니다. 폴더 이름을 바꿔도 게임 화면에는 아무 변화가 없으므로 복사한 월드가 계속 원래 이름을 표시합니다. 아래 편집기에 level.dat를 놓으면 LevelName으로 바로 이동합니다. 값을 바꾸고 저장한 뒤 파일을 원래 위치에 넣으세요.

폴더 이름을 바꿔도 달라지지 않는 이유

Minecraft는 폴더를 주소로, LevelName을 표시 이름으로 사용합니다. 월드 목록, 서버 콘솔, 월드 관리 플러그인, 채팅에 "world"를 출력하는 기능은 이 태그를 읽습니다. 따라서 cp -r worlds/hub worlds/hub2처럼 폴더를 복사하면 두 월드가 모두 자신을 hub이라고 표시하며, 파일 안의 태그를 고쳐야 해결됩니다.

서버에서는 중복 이름이 혼란을 넘어 실제 문제를 만듭니다. 텔레포트 패드, 월드별 설정, 보호 지역, 경제 배율처럼 내부 이름으로 월드를 찾는 플러그인이 엉뚱한 월드에 동작할 수 있습니다. 잘못된 이름이 캐시되기 전에 월드를 복사하는 즉시 태그를 바꾸세요.

플랫폼별 방법

Java 싱글 플레이

클라이언트의 월드 옵션 화면에서 이름을 바꾸면 LevelName도 수정됩니다. 월드가 불러와지지 않거나 사본에서 작업할 때, 또는 폴더명과 표시 이름을 의도적으로 다르게 둘 때는 파일을 직접 편집해야 합니다.

Java 서버

level-name의 server.properties은 불러올 폴더를 선택하며 이름을 바꾸지는 않습니다. 표시 이름은 LevelName의 world/level.dat에서 변경하세요.

Bedrock 및 MCPE

게임 내 월드 편집 화면에서 이름을 바꿀 수 있습니다. 서버의 월드를 수정하거나 내보낸 .mcworld를 손보는 경우에는 LevelName의 level.dat을 직접 편집하세요. Bedrock은 편집기가 처리하는 8바이트 헤더 뒤의 압축되지 않은 루트에 이 태그를 둡니다.

Bedrock 서버(PocketMine-MP, Nukkit, BDS)

파일과 태그는 같으며 서버를 먼저 중지해야 한다는 점도 같습니다. 폴더 복사 사례를 포함한 전체 절차는 서버 페이지에 있습니다.

이름이 바뀌지 않을 때

  • 서버가 실행 중이었습니다. 메모리의 사본을 다음 저장 때 파일 위에 다시 기록했습니다. 서버를 중지하고 다시 편집하세요.
  • 다른 월드를 수정했습니다. Bedrock 월드 폴더는 임의 ID를 사용합니다. 수정하기 전에 파일을 열어 LevelName으로 원하는 월드가 맞는지 확인하세요.
  • level.dat_old를 수정했습니다. 이 파일은 현재 파일이 아니라 이전 저장본입니다.
  • 런처나 패널이 이름을 캐시합니다. 일부 호스팅 패널은 월드 파일 대신 자체 데이터베이스의 이름을 표시하지만 게임 자체에는 올바르게 반영됩니다.
  • 이제 월드가 전혀 불러와지지 않습니다. 백업을 복원하고 손상된 level.dat 복구를 참고하세요.

자주 묻는 질문

월드 이름을 바꾸면 데이터가 삭제되나요?

아니요. LevelName은 표시 이름일 뿐입니다. 지형, 플레이어, 인벤토리, 엔티티는 다른 파일에 있으므로 영향을 받지 않습니다.

월드 이름에 공백, 색상, 이모지를 쓸 수 있나요?

공백은 사용할 수 있습니다. 섹션 기호 색상 코드는 일부 서버 소프트웨어에서 작동하지만 다른 곳에서는 문자 그대로 보입니다. 편집기는 에디션별 올바른 문자열 인코딩을 사용하므로 이모지도 유지되지만 콘솔과 로그 파일에서는 잘못 표시될 수 있습니다.

폴더 이름도 바꿔야 하나요?

아니요. 오히려 바꾸지 않는 편이 좋을 때가 많습니다. 서버의 level-name 설정이나 플러그인 설정이 해당 폴더 경로를 가리킬 수 있습니다. 한 번에 한 가지만 바꾸세요.

플레이어에게 새 이름이 바로 보이나요?

월드를 다시 불러오면 보입니다. 서버 목록 항목을 캐시한 클라이언트에서는 새로 고침이 필요할 수 있습니다.
