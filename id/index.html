Setiap file NBT Minecraft ditulis

NBT (Named Binary Tag) dengan beberapa metode pengkodean, setiap edisi Minecraft, peluncur dan inti server menggunakan kombinasi yang berbeda dari semua itu. Editor ini mengimplementasikan semuanya dan memilih yang paling benar berdasarkan 'byte' dalam berkas, sehingga anda tidak perlu tahu varian berkas sebelum membukanya.

Cara mengedit file NBT Minecraft

  1. Dapatkan berkas dari server atau perangkat anda. Server Java menyimpannya di world/, Server Bedrock menyimpannya di worlds/YourWorld/, Untuk Android ada di games/com.mojang/minecraftWorlds/<id>/. Hentikan server terlebih dahulu sehingga berkas tidak ditulis ketika anda menyalinnya.
  2. Letakkan ke dalam editor. Lambang di atas pohon(tree) tersebut menunjukkan apa saja yang terdeteksi — edisi, pengkodean, kompresi, dan, untuk Bedrock, versi penyimpanan dari header.
  3. Edit. Sentuh nilai untuk untuk mengubahnya di tempat. Gunakan pencarian untuk langsung ke tag berdasarkan nama atau nilai, + untuk menambahkan tag ke compound atau list apapun, × untuk menghapus compound atau list.
  4. Simpan & Unduh. Pemilih format yang dikeluarkan dan kompresi secara default mengikuti format file aslinya, sehingga pengeditan biasa menghasilkan proses bolak-balik yang mempertahankan byte aslinya..
  5. Kembalikan ke tempat semula dan mulai ulang. Simpan file aslinya sebagai cadangan sampai dunia telah dimuat sekali dan tampilannya sudah benar.

Hal yang membuat editor ini berbeda

Lima pngkodean, satu zona penempatan

Java big-endian, Bedrock little-endian, Varian jaringan NBT Bedrock, nameless-root network NBT untuk Java 1.20.2+, dan Bedrock's headered level.dat. terdeteksi, bukan sekedar dugaan.

gzip dan zlib di browser

Proses dekompresi dan rekompresi menggunakan API Compression Streams bawaan, sehingga berkas Java level.dat dapat dikonversi bolak-balik menjadi berkas yang dapat diterima oleh game tanpa perubahan apa pun.

Bilangan panjang 64-bit asli

TAG_Long Nilainya disimpan sebagai BigInt. Seed dunia dan bagian pertama UUID tetap utuh saat diedit, alih-alih rusak akibat pembulatan bilangan floating-point hal inilah yang sering menyebabkan kegagalan pada sebagian besar alat NBT di peramban.

Koreksi string encoding

Java menggunakan UTF-8 yang dimodifikasi (CESU-8), sedangkan Bedrock menggunakan UTF-8 standar. Editor mengenkode sesuai edisi, sehingga emoji dan nama-nama tempat non-Latin tetap utuh.

Bangun untuk berkas besar

Array disimpan dalam tipe array, dan struktur data tree tersebut ditampilkan secara bertahap, 200 entri setiap kali. NBT berukuran satu megabyte dapat dibuka tanpa membuat tab macet.

Telusuri seluruh tree

Temukan tag apa pun berdasarkan nama atau nilainya di mana pun dalam berkas tersebut, lalu langsung lompat ke tag tersebut dengan jalur yang telah diteruskan..

SNBT ekspor

Dump the whole tree as SNBT — the text form used by /data and datapacks — for diffing, sharing or pasting into a command.

Konversi format

Membaca berkas Bedrock, menulis berkas gzip Java dalam format big-endian, atau sebaliknya. Berguna untuk pengembangan protokol, pengujian, dan pembuatan alat bantu. .

Tidak ada data yang lepas dari perangkat anda

Berkas dibaca menggunakanFileReader, diproses dalam JavaScript, dan dikembalikan sebagai blob dalam memori. Benar-benar tidak ada yang diunggah sama sekali.

Mendukung perangkat lunak server — semua server

NBT ditentukan oleh game itu sendiri, bukan oleh implementasi server, sehingga setiap inti server yang menyimpan dunia Minecraft akan menyimpannya dalam salah satu format yang dapat dibaca oleh editor ini. Itulah daftar lengkapnya di bawah ini, dan ini bukanlah daftar pemasaran: sebuah inti server yang menulis dunia akan menyimpannya dalam format Vanilla, karena klien di sisi lain harus dapat membacanya.

Bedrock Edition — little-endian NBT, 8-byte level.dat header

Java Edition — big-endian NBT, gzip

Vanilla, CraftBukkit, Spigot, Paper, Purpur, Pufferfish, Folia, Leaves, Gale, Petal, Airplane, Sponge (SpongeVanilla, SpongeForge), Fabric, Quilt, Forge, NeoForge, Mohist, Arclight, Magma, Ketting, Banner, Cardboard, Glowstone, Thermos, Uberbukkit and every other fork, modpack server or ancient legacy build. If it writes world/level.dat, this editor opens it — details here.

Proxies and bridges

Geyser, WaterdogPE, Waterfall, Velocity and BungeeCord do not own worlds; they move NBT over the wire. Captures from those sockets are network NBT — varint little-endian on the Bedrock side, nameless-root big-endian on Java 1.20.2+ — and both open here directly.

Gunakan parser dari kode anda sendiri

Halaman ini mengekspos mesinnya ke window.NBT, sehingga parser yang sama yang menggerakkan antarmuka pengguna dapat dijalankan dari konsol browser atau digunakan kembali dalam skrip pengguna:

const bytes = new Uint8Array(await file.arrayBuffer());
const { root, format, compression, headerVersion } = await NBT.read(bytes);

root.value.find(t => t.name === "LevelName").value = "New World";

const out = await NBT.write(root, format, { compression, headerVersion });

Tags are plain objects — { type, name, value, listType } — arrays are Int8Array, Int32Array and BigInt64Array, and longs are BigInt. The full NBT format reference documents every tag type and how each encoding differs.

Pertanyaan yang sering diajukan

Apakah pengedit NBT ini gratis?

Ya, dan sumber terbuka di bawah Lisensi MIT. Tidak ada paket berbayar, tanpa pembuatan akun dan tanpa batas kuota, karena tidak ada komponen server sama sekali seluruh editor terdiri dari satu halaman statis ditambah dua berkas aset.

Apakah ini berfungsi untuk Java Edition dan Bedrock Edition?

Berfungsi untuk keduanya. File Java Edition menggunakan format big-endian dan biasanya kompresi gzip; File Bedrock menggunakan format little-endian, dan level.dat berisi tambahan 8-byte yang membuatnya lebih sulit. Editor mendeteksi varian mana yang diterimanya dan menuliskan varian yang sama kembali saat disimpan.

Apakah file dunia saya di unggah ke suatu tempat?

Tidak. File anda dibaca secara lokal dengan FileReader API dan unduhan dihasilkan dari blob yang ada di memori. Setelah halaman dimuat anda dapat memutuskan koneksi internet dan ini akan tetap bekerja..

Bisakah saya menggunakan ini di Android atau IOS?

Ya. Tata letak mobile-first dengan ukuran 44 px pada target sentuhan dan memperbaiki bar aksi. Di Android anda dapat memilih file dunia langsung dari file manager; Di iOS file dunia harus berada di aplikasi Files terlebih dahulu karena sistem sandboxing.

Apa perbedaan antara NBT dan SNBT?

NBT adalah format pengkodean biner yang digunakan Minecraft untuk menyimpan data di disk. SNBT adalah bentuk teksnya, yaitu sintaks yang anda ketikkan dalam perintah seperti /data merge. Editor ini dapat membaca NBT biner dan mengekspor SNBT, sehingga memudahkan anda untuk membandingkan dua berkas atau menyisipkan struktur ke dalam perintah.

Alat apa saja yang digantikannya?

NBT editor dekstop seperti NBTExplorer, serta berbagai alat-web-khusus yang hanya menangani satu edisi. Kunjungi Perbandingan NBTExplorer online untuk mengetahui fitur apa saja yang tersedia dan mana yang tidak.
