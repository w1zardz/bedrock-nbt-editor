Editor playerdata — File .dat Pemain Minecraft

Mendukung Minecraft Bedrock Edition dan Java Edition — serta semua core server untuk keduanya, baik yang populer maupun yang jarang dikenal: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina, dan lainnya. Daftar lengkap.

Java Edition menulis satu file NBT big-endian gzip untuk setiap pemain di world/playerdata/<uuid>.dat. File ini memuat inventaris, peti Ender, posisi, dimensi, kesehatan, rasa lapar, XP, dan atribut. Letakkan file di bawah untuk memperbaiki pemain yang terjebak dalam medan, menghapus item yang menyebabkan crash, atau mereset statistik — saat server berhenti, atau setidaknya ketika pemain tersebut offline.

Struktur tumpukan item berubah pada 1.20.5: data khusus dipindahkan dari satu compound tag ke components terpisah. Kedua struktur dapat dibuka di sini; edit struktur yang ditulis oleh versi Anda.

Perbaikan umum

  • Pemain terjebak dalam medan atau terus jatuh. Atur Pos ke koordinat aman — tiga double berurutan X, Y, Z — dan kosongkan Motion jika nilainya sangat besar.
  • Klien berhenti saat masuk. Penyebab yang umum adalah item rusak. Hapus entri bermasalah dari Inventory, jangan mengosongkan seluruh daftar.
  • Dimensi salah setelah bug portal. Atur Dimension kembali ke minecraft:overworld dan isi Pos dengan koordinat yang sesuai.
  • Terjebak dalam mode penonton. Atur playerGameType menjadi 0 untuk mode bertahan hidup atau 1 untuk mode kreatif.
  • Pengubah atribut yang tersisa dari plugin yang dihapus. Hapus entri lama dalam Attributes.

Edit saat pemain offline

Server menyimpan status pemain dalam memori dan menulisnya saat pemain keluar serta saat penyimpanan otomatis. Jika file diedit ketika pemain online, perubahan pasti tertimpa; mengedit ketika proses penyimpanan berlangsung juga dapat memotong file. Keluarkan pemain dari server — atau hentikan server — salin file, edit, lalu kembalikan sebelum pemain terhubung lagi. Simpan file asli sampai pemain berhasil masuk.

Server Bedrock tidak memakai susunan ini: data pemain berada dalam LevelDB dunia dengan kunci seperti player_<uuid>, dan nilainya berupa NBT little-endian. Ekstrak nilainya agar dapat dibuka di sini sebagai Bedrock mentah.

Pertanyaan yang sering diajukan

File mana yang menyimpan data pemain saya?

Nama file menggunakan UUID. Cari UUID pemain melalui alat penampil API Mojang, atau urutkan playerdata/ berdasarkan waktu modifikasi dan cocokkan dengan waktu masuk terakhir.

Bisakah saya memberi item kepada diri sendiri dengan mengedit playerdata?

Di server Anda sendiri, bisa — tambahkan entri ke daftar Inventory dengan id, Count, dan Slot. Melakukannya di server orang lain adalah tindakan tanpa izin dan tetap tidak akan berhasil karena server aktif menulis ulang file tersebut.

Mengapa hasil edit saya hilang?

Server atau pemain masih online saat Anda mengedit. Status pemain dalam memori akan menimpa file pada penyimpanan berikutnya.

Apakah playerdata sama di Bedrock?

Tidak. Bedrock menyimpan pemain dalam LevelDB dunia, bukan dalam file terpisah per UUID. NBT pada nilai tersebut memakai little-endian dan dapat dibuka di sini setelah diekstrak.
