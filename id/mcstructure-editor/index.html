Editor .mcstructure — File Struktur Bedrock

Mendukung Minecraft Bedrock Edition dan Java Edition — serta semua core server untuk keduanya, baik yang populer maupun yang jarang dikenal: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina, dan lainnya. Daftar lengkap.

File .mcstructure adalah NBT little-endian tanpa kompresi yang ditulis oleh structure block Bedrock. Letakkan file di bawah untuk membaca ukuran, palet blok, indeks blok, dan data entitas blok; edit bagian yang diperlukan, lalu unduh kembali dengan pengodean yang sama. Ini berguna bagi pembuat add-on dan peta yang perlu memperbaiki struktur tanpa membuka ulang dunia.

TagTipeIsinya

Indeks dalam block_indices diurutkan berdasarkan X, lalu Z, kemudian Y — indeks datarnya adalah (x * sizeZ + z) * sizeY + y pada daftar palet. Pemetaan ini memungkinkan Anda memperbaiki satu blok yang salah tanpa membuat ulang struktur.

Bagian yang biasa diubah

  • Mengganti jenis blok di semua posisi dengan mengedit satu entri dalam block_palette — setiap posisi yang menunjuk ke indeks itu ikut berubah.
  • Memperbaiki status blok, misalnya facing yang salah atau waterlogged yang tidak disengaja dalam compound states.
  • Menghapus entitas yang tidak sengaja ikut tersimpan dengan membuang entri dari daftar entities.
  • Memperbaiki data entitas blok — isi peti, teks papan, dan pengaturan spawner — di dalam block_position_data.
  • Memeriksa penanda versi pada entri palet jika struktur diimpor dengan blok yang salah setelah pembaruan gim.

Lokasi file

Structure block menyimpan file ke folder structures/ dalam direktori dunia, dengan nama <namespace>_<name>.mcstructure. Behavior pack menyimpannya dalam structures/ di dalam pack, lalu gim memuatnya berdasarkan namespace. Keduanya memakai format yang sama dan dapat dibuka di sini.

Padanan Java Edition adalah file struktur .nbt big-endian gzip — pengodeannya berbeda dan susunan tag-nya juga berbeda. Halaman editor Java menjelaskan file tersebut, dan editor ini juga dapat membukanya.

Pertanyaan yang sering diajukan

Bisakah .mcstructure dikonversi menjadi struktur .nbt Java?

Editor dapat mengodekan ulang byte menjadi big-endian gzip, tetapi susunan tag berbeda — struktur Java menggunakan palette/blocks dengan kunci dan nama blok yang berbeda. File hasil pengodean ulang dapat dibaca, tetapi bukan struktur Java yang valid.

Mengapa .mcstructure saya tidak dikompresi?

Bedrock menulis file struktur sebagai NBT little-endian mentah tanpa pembungkus gzip. Ini normal; editor mendeteksinya sebagai Bedrock mentah.

Apa arti indeks -1 dalam block_indices?

Nilai tersebut menandai posisi yang tidak diubah oleh struktur, sehingga blok yang sudah ada di dunia tetap dipertahankan saat struktur ditempatkan.

Bisakah ukuran struktur diubah dengan mengedit size?

Tidak hanya dengan itu — block_indices memiliki satu entri untuk setiap posisi, sehingga panjang array harus sama persis dengan volume baru. Mengubah size saja menghasilkan file yang ditolak gim.
