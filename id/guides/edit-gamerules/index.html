Mengedit Aturan Permainan dalam level.dat

Mendukung Minecraft Bedrock Edition dan Java Edition — serta semua core server untuk keduanya, baik yang populer maupun yang jarang dikenal: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina, dan lainnya. Daftar lengkap.

Aturan permainan tersimpan dalam level.dat, jadi Anda dapat mengubahnya tanpa memuat dunia atau mengaktifkan cheat — berguna ketika dunia tidak dapat dijalankan, cheat dinonaktifkan, atau Anda menyiapkan salinan dunia sebelum pemain masuk. Java menyimpannya sebagai string dalam compound GameRules; Bedrock menyimpan setiap aturan sebagai tag byte huruf kecil tersendiri di root.

Java: compound GameRules berisi string

Dalam Java Edition, Data → GameRules menyimpan satu TAG_String untuk setiap aturan dengan nama persis seperti yang digunakan /gamerule, sedangkan nilainya ditulis sebagai teks: "true", "false", atau angka. Aturan yang belum pernah diatur tidak ada dalam file dan memakai nilai bawaan — menambahkan tag dengan nama yang benar dan nilai string bekerja persis seperti menjalankan perintah.

Bedrock: tag byte huruf kecil terpisah

Bedrock tidak mengelompokkan aturan. Setiap aturan berupa TAG_Byte pada root level.dat, memakai nama berhuruf kecil, dan berisi 1 atau 0 — keepinventory, domobspawning, domobloot, dodaylightcycle, doweathercycle, mobgriefing, firedamage, falldamage, drowningdamage, pvp, showcoordinates, commandblockoutput, sendcommandfeedback, naturalregeneration, tntexplodes, respawnblocksexplode, showdeathmessages, doimmediaterespawn. Aturan angka seperti randomtickspeed dan functioncommandlimit menggunakan TAG_Int.

Untuk mengatur aturan yang belum ada, tambahkan tag dengan tipe yang tepat: Byte untuk sakelar dan Int untuk angka. Aturan yang tersimpan dengan tipe salah akan diabaikan atau membuat dunia gagal dimuat.

Kapan mengedit file lebih tepat daripada memakai perintah

  • Cheat dinonaktifkan dan Anda tidak ingin mengaktifkan lalu menonaktifkannya hanya untuk menjalankan satu perintah.
  • Dunia tidak dapat dimuat — aturan seperti doImmediateRespawn dapat diatur sebelum pemain pertama masuk.
  • Anda menyiapkan dunia templat yang akan disalin ke banyak server dan ingin aturan sudah tertanam dalam salinan.
  • Plugin mengubah aturan dan Anda ingin melihat nilai yang benar-benar tersimpan, bukan hanya yang dilaporkan perintah.
  • Edit massal. Mengatur belasan aturan di beberapa dunia lebih cepat dilakukan dalam file daripada lewat chat.

Hentikan server terlebih dahulu, seperti pada setiap pengeditan level.dat — dunia yang masih berjalan menulis ulang file saat menyimpan dan akan membuang perubahan.

Pertanyaan yang sering diajukan

Mengapa aturan permainan disimpan sebagai string di Java?

Java menyimpan setiap aturan permainan sebagai string, termasuk boolean dan angka. Tulis "true", bukan byte bernilai 1.

Mengapa Bedrock menyimpannya sebagai byte?

Bedrock menyimpan sakelar sebagai tag byte di root dan aturan angka sebagai int. Tidak ada compound GameRules.

Sebuah aturan sama sekali tidak ada dalam file.

Artinya, aturan tersebut memakai nilai bawaan. Tambahkan tag dengan nama persis dan tipe yang benar agar dunia memakai nilai Anda.

Apakah aturan permainan ikut tersalin bersama folder dunia?

Ya — aturan tersimpan dalam level.dat, sehingga dunia hasil salinan mewarisinya bersama nama dunia lamanya.
