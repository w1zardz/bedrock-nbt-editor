Cara Mengubah Nama Dunia Minecraft

Mendukung Minecraft Bedrock Edition dan Java Edition — serta semua core server untuk keduanya, baik yang populer maupun yang jarang dikenal: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina, dan lainnya. Daftar lengkap.

Nama tampilan dunia tersimpan dalam tag LevelName di level.dat, bukan pada nama folder. Mengganti nama folder tidak mengubah apa pun yang ditampilkan gim. Karena itu, dunia hasil salinan tetap memakai nama aslinya. Masukkan level.dat ke editor di bawah — editor langsung membuka LevelName — ubah nilainya, simpan, lalu kembalikan file tersebut.

Mengapa mengganti nama folder tidak berpengaruh

Minecraft memakai folder sebagai alamat dan LevelName sebagai label. Daftar dunia, konsol server, plugin pengelola dunia, dan semua komponen yang menampilkan "dunia" di obrolan membaca tag tersebut. Jadi, menyalin folder — cp -r worlds/hub worlds/hub2 — menghasilkan dua dunia yang sama-sama mengaku bernama hub, dan satu-satunya perbaikan ada di dalam file.

Di server, nama duplikat bukan hanya membingungkan. Plugin yang mencari dunia berdasarkan nama internal dapat bertindak pada dunia yang salah: pad teleportasi, konfigurasi per dunia, wilayah perlindungan, dan pengali ekonomi. Ganti nama tag segera setelah menyalin dunia, sebelum komponen lain menyimpannya dalam cache.

Menurut platform

Java pemain tunggal

Klien menyediakan opsi ganti nama pada layar pengaturan dunia dan mengedit LevelName untuk Anda. Mengedit file secara manual diperlukan ketika dunia tidak dapat dimuat, saat Anda mengerjakan salinannya, atau ketika nama folder dan label sengaja dibuat berbeda.

Server Java

level-name dalam server.properties memilih folder yang akan dimuat. Pengaturan itu tidak mengganti nama apa pun. Ubah LevelName dalam world/level.dat untuk mengubah label.

Bedrock dan MCPE

Layar edit dunia dalam gim dapat mengganti nama dunia. Jika dunia berada di server atau Anda memperbaiki file .mcworld hasil ekspor, edit LevelName langsung dalam level.dat — Bedrock menyimpannya langsung di root tanpa kompresi, setelah header 8 byte yang ditangani otomatis oleh editor.

Server Bedrock (PocketMine-MP, Nukkit, BDS)

File dan tag-nya sama, begitu pula peringatan untuk menghentikan server terlebih dahulu. Halaman server menjelaskan alur lengkap, termasuk kasus penyalinan folder.

Jika nama tidak berubah

  • Server masih berjalan. Salinan di memori ditulis kembali menimpa file Anda saat penyimpanan berikutnya. Hentikan server dan ulangi pengeditan.
  • Anda mengedit dunia yang salah. Folder dunia Bedrock memakai id acak. Buka file dan baca LevelName untuk memastikan dunianya benar sebelum mengedit.
  • Anda mengedit level.dat_old. Itu adalah penyimpanan sebelumnya, bukan file aktif.
  • Launcher atau panel menyimpan nama dalam cache. Beberapa panel hosting menampilkan nama dari basis datanya sendiri, bukan dari file dunia; nama di dalam gim tetap benar.
  • Sekarang dunia sama sekali tidak dapat dimuat. Pulihkan cadangan dan baca cara memperbaiki level.dat yang rusak.

Pertanyaan yang sering diajukan

Apakah mengganti nama dunia menghapus sesuatu?

Tidak. LevelName hanyalah label. Medan, pemain, inventaris, dan entitas tersimpan dalam file lain dan tidak tersentuh.

Bisakah nama dunia memakai spasi, warna, atau emoji?

Spasi dapat digunakan. Kode warna dengan simbol § berfungsi pada beberapa perangkat lunak server, tetapi muncul sebagai karakter biasa di tempat lain. Emoji tetap utuh setelah diedit karena editor memakai pengodean string yang tepat untuk setiap edisi, tetapi konsol dan file log mungkin tidak menampilkannya dengan baik.

Apakah nama folder juga harus diubah?

Tidak, dan sering kali sebaiknya jangan — pengaturan level-name server atau konfigurasi plugin mungkin mengarah ke path folder tersebut. Ubah satu hal setiap kali.

Apakah pemain langsung melihat nama baru?

Ya, setelah dunia dimuat ulang. Klien yang menyimpan entri daftar server dalam cache mungkin perlu disegarkan.
