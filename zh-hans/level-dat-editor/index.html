level.dat 编辑器｜在线修改 Minecraft 世界设置

支持 Minecraft 基岩版和 Java 版，也支持两者所有常见或少见的服务端核心：Vanilla、Paper、Spigot、Purpur、Folia、Fabric、Forge、NeoForge、Mohist、Sponge、Bedrock Dedicated Server、PocketMine-MP、Nukkit、PowerNukkitX、Cloudburst、Dragonfly、Endstone、LeviLamina 等。完整列表。

level.dat 保存 Minecraft 世界自身的全部核心信息，包括名称、游戏模式、难度、出生点、游戏规则、天气状态，以及最后打开该世界的版本。将文件拖入下方即可直接修改这些值。Java 文件（gzip、大端序）和基岩版文件（小端序、带 8 字节文件头）均受支持，保存时会按输入文件的原格式写回。

Java 版 level.dat 几乎把所有内容都放在一个 Data 复合标签中；基岩版 level.dat 则将标签平铺在根节点。下面列出值得了解的名称；在树中搜索任意名称，编辑器会直接跳转到对应标签。

安全编辑

  • 先停止服务器或关闭游戏。Minecraft 会在自动保存和关闭时重写 level.dat。运行中的服务器会覆盖编辑结果，甚至可能覆盖尚未复制完整的文件。
  • 保留原文件。本编辑器不会修改拖入的文件，而会生成新的下载文件。在世界成功加载一次之前，请保留旧副本。
  • 不要更改标签类型。将 Difficulty 从 Byte 改为 Int，或重命名 Minecraft 所需的标签，都可能导致世界无法加载。除非明确了解原因，否则只修改值，不修改结构。
  • 保持基岩版文件头完整。8 字节文件头包含存储版本和负载长度。编辑器会自动重写长度并保留版本；手动编辑时丢失文件头会导致文件无法加载。

常见问题

无需下载软件就能编辑 level.dat 吗？

可以，这正是本页面的用途。解析器在浏览器中运行，因此无需安装任何内容；只要使用现代浏览器，就不受操作系统限制。

为什么世界仍显示旧名称？

因为世界列表中的名称来自 LevelName，该标签位于 level.dat 内，而不是文件夹名称。复制或重命名文件夹不会改动该标签；编辑标签后，列表就会更新。

它支持 level.dat_old 吗？

支持。level.dat_old 是采用相同格式的上一次存档。如果当前文件损坏，请打开 _old 副本，确认数据正常后以原文件名恢复。

可以在这里修改世界种子吗？

可以修改种子标签，但它只影响修改后新生成的地形。磁盘中已有的区块会保持原有形状，因此新旧地形的交界处可能清晰可见。

编辑 level.dat 会导致封禁或损坏世界吗？

这是你自己的存档文件，不涉及封禁。损坏通常来自服务器运行时编辑，或修改标签类型和名称而不是值。请先停止服务器，只编辑值并保留备份。
