Schematic 编辑器｜在线修改 .schem 和 .schematic

支持 Minecraft 基岩版和 Java 版，也支持两者所有常见或少见的服务端核心：Vanilla、Paper、Spigot、Purpur、Folia、Fabric、Forge、NeoForge、Mohist、Sponge、Bedrock Dedicated Server、PocketMine-MP、Nukkit、PowerNukkitX、Cloudburst、Dragonfly、Endstone、LeviLamina 等。完整列表。

Schematic 是 gzip 压缩的大端序 NBT。将现代 WorldEdit .schem（Sponge Schematic 格式）或旧版 MCEdit .schematic 拖入下方，即可检查调色板、尺寸、偏移量、方块实体列表和元数据，编辑任意标签，再下载可直接用于 //paste 的文件。

同一扩展名系列中的两种格式

格式扩展名关键标签
Sponge Schematic v2 (WorldEdit 7).schemVersion, DataVersion, Width, Height, Length, Palette, BlockData, BlockEntities, Offset, Metadata
Sponge Schematic v3.schem相同数据嵌套在 Schematic 复合标签下，Blocks 中包含 Palette 和 Data
旧版 MCEdit.schematicWidth, Height, Length, Blocks, Data, Entities, TileEntities, Materials

Sponge 格式中的 BlockData 是 varint 调色板索引的 byte 数组，并非每个方块一个字节；较大的 ID 会跨越多个字节。旧格式则在 Blocks 中存储原始数字方块 ID，并用平行的 Data 数组存储元数据半字节，因此旧原理图在现代版本中会丢失精确信息。

适合手动修改的内容

  • 调色板项目。将 minecraft:oak_planks 改为 minecraft:spruce_planks，修改位置在 Palette 中，可一次替换原理图中所有匹配方块。
  • 偏移量和原点。Offset 决定粘贴位置相对玩家的位置，可快速修复始终偏离几个方块的建筑。
  • 方块实体。箱子物品、告示牌文本和刷怪笼数据位于 BlockEntities，分享建筑前可以清理。
  • 元数据。Metadata 保存作者和 WorldEdit 原点；可以安全编辑，发布前通常适合清除。
  • DataVersion。它说明生成原理图的 Minecraft 版本，可解释大多数粘贴时的“未知方块”错误。

加载器兼容性

WorldEdit 和 FastAsyncWorldEdit 读取 .schem，位置为 plugins/WorldEdit/schematics/；旧 .schematic 仍可加载，但会在导入时转换。Litematica 使用自己的 .litematic 容器，它也是 NBT，能在本编辑器中打开，但布局不同于 Sponge。无论具体格式如何，编辑器都会按 NBT 读取，并以 gzip 压缩写回，使加载器获得预期文件。

常见问题

没有服务器或 WorldEdit 能打开 .schem 吗？

可以。.schem 就是 gzip 大端序 NBT；无需安装其他软件，编辑器可直接在浏览器中打开。

为什么原理图粘贴后方块错误？

通常是版本不匹配。请检查 DataVersion 和调色板；较新版本导出的原理图可能引用旧服务器不认识的方块状态。

可以在这里修改原理图尺寸吗？

不能只修改 Width/Height/Length。BlockData 的大小对应体积，尺寸与数据必须一起改变；此操作应使用 WorldEdit，而不是标签编辑器。

可以打开 .litematic 文件吗？

可以按 NBT 打开。Litematica 使用自己的标签布局，不是 Sponge 格式，因此显示的是其原生结构，而不是 Schematic 调色板。
