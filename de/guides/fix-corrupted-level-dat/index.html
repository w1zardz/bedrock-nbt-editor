Beschädigte level.dat reparieren

Unterstützt Minecraft Bedrock Edition und Java Edition – einschließlich jedes bekannten oder seltenen Serverkerns: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina und weitere. Vollständige Liste.

Wenn eine Welt nicht lädt, liegt meist eines von vier Problemen vor: level.dat wurde bei einem Absturz während des Speicherns abgeschnitten, nach einer manuellen Änderung wurde die falsche Komprimierung verwendet, die Bedrock-Header-Länge ist falsch oder der Typ eines Tags wurde geändert. Ziehe die Datei nach unten. Der Editor meldet genau, wo das Parsen beendet wurde, und grenzt die Ursache schnell ein.

Eine Welt ohne level.dat retten

Gelände, Truhen und Spieler einer Welt liegen nicht in level.dat, sondern in region/ bei Java oder db/ bei Bedrock. Ist die Metadatendatei nicht mehr reparierbar, erstelle mit derselben Version und denselben Einstellungen eine neue Welt. Verschiebe anschließend die Chunk-Daten dorthin und trage LevelName, Spawnkoordinaten und Spielregeln in der neuen Datei ein. Verloren gehen die Metadaten, nicht die Bauwerke. Prüfe zuerst die Version: Eine Java-Welt enthält DataVersion. Die neu erzeugte Datei darf nicht älter sein als die importierten Chunks.

Erneute Beschädigung verhindern

  • Stoppe den Server vor dem Kopieren oder Bearbeiten. Viele Beschädigungen entstehen, wenn eine Datei während eines Schreibvorgangs kopiert wird.
  • Erstelle geplante Snapshots außerhalb des Rechners. Eine Sicherung auf demselben Datenträger übersteht den Speicherfehler nicht, der das Problem verursacht hat.
  • Verwende save-off / save-all für Snapshots im laufenden Betrieb, damit die Kopie aus einer ruhenden Welt erstellt wird.
  • Überwache den freien Speicherplatz. Ein voller Datenträger schneidet Speichervorgänge unbemerkt ab; level.dat wird zuletzt geschrieben.
  • Bearbeite Werte statt der Struktur. Das Umbenennen von Tags oder Ändern ihrer Typen kann das Spiel nicht ausgleichen.

Häufig gestellte Fragen

Was ist level.dat_old?

Der vorherige Speicherstand. Minecraft benennt die aktuelle Datei vor dem Schreiben einer neuen in level.dat_old um. Dadurch entsteht ohne zusätzlichen Aufwand eine Sicherung der vorherigen Generation, die zuerst getestet werden sollte.

Kann ein NBT-Editor eine abgeschnittene Datei reparieren?

Er kann genau zeigen, an welcher Stelle die Daten enden. Fehlende Bytes lassen sich aber nicht rekonstruieren. Bei nur teilweise lesbaren Daten benötigst du eine Sicherung.

Verliere ich meine Bauwerke?

Nicht allein durch eine beschädigte Datei level.dat. Chunks liegen in region/ oder db/. Eine neue Weltdatei derselben Version kann diese Daten übernehmen.

Der Server meldet level.dat als fehlerfrei, aber die Welt ist leer.

Dann liegt das Problem im Chunk-Speicher und nicht in den Metadaten. Prüfe, ob region/ oder db/ mitkopiert wurden und ob die Spawnkoordinaten in level.dat auf die erwartete Position zeigen.
