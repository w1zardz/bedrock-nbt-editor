Schematic Editor – .schem und .schematic online

Unterstützt Minecraft Bedrock Edition und Java Edition – einschließlich jedes bekannten oder seltenen Serverkerns: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina und weitere. Vollständige Liste.

Schematics sind gzip-komprimiertes Big-Endian-NBT. Ziehe eine moderne WorldEdit-Datei .schem im Sponge-Schematic-Format oder eine ältere MCEdit-Datei .schematic nach unten. Du kannst Palette, Abmessungen, Offsets, Block-Entity-Liste und Metadaten prüfen, beliebige Tags bearbeiten und die Datei für //paste wieder herunterladen.

Zwei Formate, eine Familie von Dateiendungen

FormatEndungWichtige Tags
Sponge Schematic v2 (WorldEdit 7).schemVersion, DataVersion, Width, Height, Length, Palette, BlockData, BlockEntities, Offset, Metadata
Sponge Schematic v3.schemDieselben Daten in einem Compound Schematic; Blocks enthält Palette und Data
Älteres MCEdit-Format.schematicWidth, Height, Length, Blocks, Data, Entities, TileEntities, Materials

BlockData ist in den Sponge-Formaten ein Byte-Array aus Varint-Palettenindizes und nicht ein Byte pro Block. Lange IDs werden über mehrere Bytes fortgesetzt. Das alte Format speichert dagegen numerische Block-IDs direkt in Blocks und Metadaten-Nibbles parallel in Data. Deshalb verlieren alte Schematics in modernen Versionen Informationen.

Sinnvolle manuelle Änderungen

  • Paletteneinträge. Wenn du minecraft:oak_planks durch minecraft:spruce_planks in Palette ersetzt, werden alle passenden Blöcke im Schematic gleichzeitig geändert.
  • Offset und Ursprung. Offset bestimmt die Position relativ zu dir. Damit lässt sich ein Bauwerk korrigieren, das immer um einige Blöcke versetzt eingefügt wird.
  • Block-Entities. Truheninventare, Schildzeilen und Spawner-Daten liegen in BlockEntities und können vor dem Teilen bereinigt werden.
  • Metadaten. Metadata enthält Autor und WorldEdit-Ursprung. Diese Angaben können bearbeitet und vor einer Veröffentlichung entfernt werden.
  • DataVersion. Zeigt, mit welcher Minecraft-Version das Schematic erzeugt wurde, und erklärt die meisten Fehler zu unbekannten Blöcken beim Einfügen.

Kompatibilität der Loader

WorldEdit und FastAsyncWorldEdit lesen .schem aus plugins/WorldEdit/schematics/. Alte Dateien .schematic werden weiterhin geladen, dabei aber konvertiert. Litematica verwendet den eigenen NBT-Container .litematic. Auch er lässt sich hier öffnen, obwohl seine Struktur vom Sponge-Format abweicht. Unabhängig von der Variante liest der Editor die Datei als NBT und schreibt sie gzip-komprimiert zurück, damit der Loader das erwartete Format erhält.

Häufig gestellte Fragen

Kann ich eine .schem-Datei ohne Server oder WorldEdit öffnen?

Ja. Eine Datei .schem ist lediglich gzip-komprimiertes Big-Endian-NBT. Der Editor öffnet sie ohne weitere Installation im Browser.

Warum wird mein Schematic mit falschen Blöcken eingefügt?

Meist liegt ein Versionskonflikt vor. Prüfe DataVersion und die Palette. Ein mit einer neueren Version exportiertes Schematic kann Blockzustände enthalten, die ein älterer Server nicht kennt.

Kann ich die Größe eines Schematics hier ändern?

Nicht allein durch das Bearbeiten von Width/Height/Length. BlockData ist auf das Volumen abgestimmt; Abmessungen und Daten müssen gemeinsam geändert werden. Dafür ist WorldEdit statt eines Tag-Editors zuständig.

Öffnet der Editor .litematic-Dateien?

Ja, als NBT. Die eigene Tag-Struktur von Litematica entspricht nicht der Sponge-Struktur. Angezeigt wird daher die native Struktur und keine Schematic-Palette.
