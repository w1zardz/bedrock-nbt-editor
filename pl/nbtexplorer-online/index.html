NBTExplorer Online — Browser Alternative

Supports Minecraft Bedrock Edition and Java Edition — and every server core for both, popular or obscure: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina and the rest. Full list.

NBTExplorer is the desktop tag editor most Minecraft players know, and it needs .NET or Mono, a download and a desktop. This page does the same job — tag tree, inline editing, add and remove tags — in the browser, on any operating system including phones, and it also reads Bedrock little-endian files, which NBTExplorer does not.

The honest summary: if you need to walk a whole region folder and open chunks by coordinate, the desktop tool still wins. If you need to open one file — a level.dat, a player file, a schematic, a Bedrock world — on whatever machine you happen to be at, this is faster and covers editions the desktop tool never learned.

Coming from the desktop tool

  • The tree works the same way. Expand compounds and lists, click a value to edit it, use + and × for structure.
  • Types are enforced the same way. A byte stays a byte; out-of-range values are rejected instead of being silently truncated.
  • Saving is a download, not an in-place write. The file you dropped in is never modified, so your backup is automatic.
  • Compression is round-tripped. A gzip file goes back out gzip, so the game accepts it without a manual recompress step.
  • Bedrock just works. No separate tool, no hex editor to fix the header length after an edit.

Where other tools still fit

Use NBTExplorer or NBTStudio for bulk region browsing. Use Amulet or MCA Selector for chunk-level surgery and world trimming. Use WorldEdit for anything geometric. Use this page when the job is "open this one file, change these tags, give it back" — which is most of the time — or when the file is Bedrock and the desktop tools refuse it.

Frequently Asked Questions

Is there an official NBTExplorer web version?

No. NBTExplorer is a desktop application; this is an independent editor that covers the same everyday tasks in the browser and adds Bedrock support.

Does it work on macOS and Linux without Mono?

Yes — it is a web page. Any current browser on macOS, Linux, Windows, Android or ChromeOS runs it.

Can it open a whole region file like NBTExplorer does?

No. It edits a single NBT document at a time. Extract a chunk from the .mca first, then drop the payload here.

Is it safe to use for my only save?

It never writes to the file you open — edits come back as a new download — but keep your own backup anyway, as with any editor.
