Modificare le regole di gioco in level.dat

Supporta Minecraft Bedrock Edition e Java Edition e ogni core server per entrambe, diffuso o meno: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina e gli altri. Elenco completo.

Le regole di gioco sono archiviate in level.dat, quindi puoi modificarle senza caricare il mondo né attivare i trucchi. È utile se il mondo non si avvia, se i trucchi sono disabilitati o se prepari una copia prima dell'accesso dei giocatori. Java le conserva come stringhe in un compound GameRules; Bedrock usa per ciascuna un tag byte minuscolo nella radice.

keepInventorydoDaylightCyclemobGriefingcommandBlockOutputrandomTickSpeed

Java: un compound GameRules di stringhe

In Java Edition, Data → GameRules contiene un TAG_String per ogni regola, identificato dal nome esatto usato da /gamerule, con il valore scritto come testo: "true", "false" o un numero. Le regole mai impostate nel mondo sono semplicemente assenti e assumono il valore predefinito. Aggiungere il tag con nome corretto e valore stringa equivale a eseguire il comando.

RegolaValoreEffetto
keepInventory"true"Conserva gli oggetti dopo la morte
doDaylightCycle"false"Blocca l'ora del giorno
doWeatherCycle"false"Blocca le condizioni meteo
mobGriefing"false"Impedisce a creeper ed enderman di modificare i blocchi
doMobSpawning"false"Disattiva la generazione naturale dei mob
doFireTick"false"Impedisce al fuoco di propagarsi
commandBlockOutput"false"Nasconde in chat l'output dei blocchi di comando
randomTickSpeed"3"Velocità di crescita delle colture e propagazione del fuoco
playersSleepingPercentage"50"Percentuale di giocatori necessaria per saltare la notte
spawnRadius"10"Estensione dell'area di generazione

Le maiuscole sono significative. keepinventory in un file Java non è lo stesso tag di keepInventory e verrà ignorato.

Bedrock: singoli tag byte in minuscolo

Bedrock non raggruppa le regole. Ciascuna è un TAG_Byte nella radice di level.dat, con nome minuscolo e valore 1 o 0: keepinventory, domobspawning, domobloot, dodaylightcycle, doweathercycle, mobgriefing, firedamage, falldamage, drowningdamage, pvp, showcoordinates, commandblockoutput, sendcommandfeedback, naturalregeneration, tntexplodes, respawnblocksexplode, showdeathmessages, doimmediaterespawn. Le regole numeriche come randomtickspeed e functioncommandlimit sono invece TAG_Int.

Per impostare una regola non ancora presente, aggiungi il tag con il tipo corretto: Byte per un interruttore, Int per un numero. Una regola archiviata con il tipo sbagliato viene ignorata oppure impedisce il caricamento.

Quando modificare il file invece di usare il comando

  • I trucchi sono disattivati e non vuoi abilitarli solo per eseguire un comando.
  • Il mondo non si carica: puoi impostare una regola come doImmediateRespawn prima del primo accesso.
  • Stai preparando un mondo modello da copiare su più server e vuoi includere le regole nella copia.
  • Un plugin ha cambiato una regola e vuoi controllare il valore realmente archiviato invece di quello riportato da un comando.
  • Modifiche in serie. Impostare una dozzina di regole su più mondi è più rapido nel file che in chat.

Arresta prima il server, come per qualsiasi modifica a level.dat: un mondo in esecuzione riscrive il file al salvataggio e annulla la modifica.

Domande frequenti

Perché in Java la regola è archiviata come stringa?

Java archivia tutte le regole di gioco come stringhe, compresi valori booleani e numeri. Scrivi "true", non un byte con valore 1.

Perché in Bedrock è un byte?

Bedrock archivia gli interruttori come tag byte nella radice e le regole numeriche come int. Non esiste un compound GameRules.

Una regola è del tutto assente dal file.

Significa che usa il valore predefinito. Aggiungi il tag con il nome esatto e il tipo corretto: il mondo userà il valore specificato.

Le regole vengono copiate con la cartella del mondo?

Sì: si trovano in level.dat, quindi un mondo copiato le eredita insieme al nome del mondo non aggiornato.
