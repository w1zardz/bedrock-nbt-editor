Come cambiare nome a un mondo Minecraft

Supporta Minecraft Bedrock Edition e Java Edition e ogni core server per entrambe, diffuso o meno: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina e gli altri. Elenco completo.

Il nome visualizzato di un mondo si trova nel tag LevelName dentro level.dat, non nel nome della cartella. Rinominare la cartella non cambia ciò che mostra il gioco, quindi una copia continua a presentarsi con il nome originale. Trascina level.dat nell'editor: verrà aperto direttamente LevelName. Modifica il valore, salva e rimetti il file al suo posto.

Perché rinominare la cartella non basta

Minecraft usa la cartella come indirizzo e LevelName come etichetta. L'elenco dei mondi, la console del server, i plugin di gestione e qualsiasi funzione che mostri il «mondo» in chat leggono questo tag. Una copia della cartella — cp -r worlds/hub worlds/hub2 — produce quindi due mondi che dichiarano entrambi di chiamarsi hub; la correzione va fatta nel file.

Su un server il duplicato può causare problemi concreti. I plugin che identificano i mondi tramite il nome interno possono agire su quello sbagliato: teletrasporti, configurazioni per mondo, regioni protette, moltiplicatori dell'economia. Rinomina il tag appena copi il mondo, prima che venga memorizzato nella cache.

Per piattaforma

Java in giocatore singolo

Il client consente di rinominare il mondo nella schermata delle opzioni e modifica LevelName automaticamente. La modifica manuale serve se il mondo non si carica, se lavori su una copia oppure se vuoi intenzionalmente nomi diversi per cartella ed etichetta.

Server Java

level-name in server.properties seleziona la cartella da caricare; non rinomina nulla. Per cambiare l'etichetta, modifica LevelName in world/level.dat.

Bedrock e MCPE

La schermata di modifica del mondo nel gioco permette di rinominarlo. Quando il mondo si trova su un server o devi modificare un file .mcworld esportato, intervieni direttamente su LevelName in level.dat. Bedrock lo archivia nella radice, senza compressione, dopo l'intestazione di 8 byte gestita dall'editor.

Server Bedrock (PocketMine-MP, Nukkit, BDS)

Il file e il tag sono gli stessi, così come la necessità di arrestare prima il server. La pagina dedicata ai server descrive la procedura completa, compreso il caso della copia di una cartella.

Se il nome non cambia

  • Il server era in esecuzione. Al salvataggio successivo, la copia in memoria ha sovrascritto il file. Arresta il server e ripeti la modifica.
  • Hai modificato il mondo sbagliato. Le cartelle dei mondi Bedrock hanno id casuali. Prima di intervenire, apri il file e leggi LevelName per verificare che sia quello corretto.
  • Hai modificato level.dat_old. È il salvataggio precedente, non il file attivo.
  • Un launcher o un pannello conserva il nome nella cache. Alcuni pannelli di hosting mostrano un nome preso dal proprio database invece che dal file del mondo; nel gioco il nome sarà comunque corretto.
  • Ora il mondo non si carica. Ripristina il backup e consulta la guida per riparare un level.dat danneggiato.

Domande frequenti

Rinominare un mondo elimina qualcosa?

No. LevelName è solo un'etichetta. Terreno, giocatori, inventari ed entità si trovano in altri file e non vengono modificati.

Posso usare spazi, colori o emoji nel nome?

Gli spazi sono consentiti. I codici colore con il simbolo di sezione funzionano su alcuni server e altrove appaiono come caratteri letterali. Le emoji restano intatte perché l'editor usa la codifica corretta per ogni edizione, ma console e file di log potrebbero visualizzarle male.

Devo rinominare anche la cartella?

No, e spesso è meglio non farlo: l'impostazione level-name del server o la configurazione di un plugin potrebbe fare riferimento al percorso della cartella. Cambia un elemento alla volta.

I giocatori vedranno subito il nuovo nome?

Sì, dopo il ricaricamento del mondo. I client che hanno memorizzato una voce dell'elenco server potrebbero richiedere un aggiornamento.
