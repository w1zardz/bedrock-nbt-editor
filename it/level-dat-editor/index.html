Editor level.dat — modifica le impostazioni di Minecraft

Supporta Minecraft Bedrock Edition e Java Edition e ogni core server per entrambe, diffuso o meno: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina e gli altri. Elenco completo.

level.dat è il file che contiene tutto ciò che un mondo Minecraft conosce di sé: nome, modalità di gioco, difficoltà, punto di spawn, regole di gioco, stato meteorologico e versione con cui è stato aperto l'ultima volta. Trascinalo qui sotto per modificare direttamente questi valori. Sono supportati sia i file Java (gzip, big-endian) sia quelli Bedrock (little-endian con intestazione di 8 byte); il file viene riscritto nel formato originale.

Minecraft scrive anche un level.dat_old accanto al file: è il salvataggio precedente. Anche questo si apre nell'editor ed è il primo file da provare se quello corrente non si carica.

Modificare in sicurezza

  • Arresta prima il server o chiudi il gioco. Minecraft riscrive level.dat durante il salvataggio automatico e all'arresto; un server in esecuzione sovrascriverà la modifica o, peggio, scriverà su un file copiato solo in parte.
  • Conserva l'originale. Questo editor non modifica mai il file trascinato, ma produce un nuovo download. Conserva la vecchia copia finché il mondo non è stato caricato almeno una volta.
  • Non cambiare i tipi dei tag. Cambiare Difficulty da Byte a Int o rinominare un tag atteso da Minecraft può impedire il caricamento del mondo. Modifica i valori, non la struttura, salvo che tu sappia perché farlo.
  • Mantieni intatta l'intestazione Bedrock. L'intestazione di 8 byte contiene la versione di archiviazione e la lunghezza del payload. L'editor riscrive automaticamente la lunghezza e conserva la versione; i file modificati manualmente che la perdono non si caricano.

Domande frequenti

Posso modificare level.dat senza scaricare programmi?

Sì, questa pagina serve proprio a questo. Il parser viene eseguito nel browser, quindi non c'è nulla da installare e basta un browser aggiornato su qualsiasi sistema operativo.

Perché il mondo mostra ancora il vecchio nome?

Perché il nome nell'elenco dei mondi proviene da LevelName in level.dat, non dal nome della cartella. Copiare o rinominare una cartella non modifica il tag. Modificalo per aggiornare l'elenco.

Funziona con level.dat_old?

Sì. level.dat_old è il salvataggio precedente nello stesso formato. Se il file corrente è danneggiato, apri la copia _old, verifica che i dati siano corretti e ripristinala con il nome originale.

Posso cambiare qui il seed del mondo?

Puoi modificare il tag del seed, ma influirà solo sul terreno generato dopo la modifica. I chunk già presenti su disco manterranno la forma originale, quindi il confine tra il terreno vecchio e quello nuovo sarà visibile.

Modificare level.dat può causare un ban o danneggiare il mondo?

È un tuo file di salvataggio, quindi non comporta un ban. I danni derivano dalla modifica mentre il server è in esecuzione o dal cambiamento di tipi e nomi dei tag anziché dei valori. Arresta il server, modifica i valori e conserva un backup.
