Leggere un file creato da altri

Uno dei motivi principali per aprire un file NBT è la diagnosi: quale versione lo ha scritto, perché il mondo non viene caricato, che cosa contiene davvero lo schematic ricevuto. Il visualizzatore mostra ogni tag con il suo tipo esatto, consentendo di distinguere un TAG_Byte con valore 1 da un TAG_Int con valore 1: una differenza importante per Minecraft che i dump di testo in genere non conservano.

  • Indicatore del tipo in ogni riga — Byte, Short, Int, Long, Float, Double, Byte[], String, List, Compound, Int[], Long[].
  • Long completi a 64 bit mostrati con precisione, così seed e metà degli UUID vengono letti correttamente senza arrotondamenti.
  • Ricerca nell'intero albero per nome o valore del tag, con passaggio diretto al risultato.
  • Formato rilevato mostrato nella barra del file: edizione, ordine dei byte, compressione e versione di archiviazione Bedrock.
  • Esportazione SNBT per ottenere l'intero documento come testo da confrontare, incollare in un comando o passare a un altro strumento.

NBT e SNBT

SNBT è la forma testuale di NBT: è ciò che stampa /data get e che accettano i comandi. Conserva le informazioni sul tipo tramite suffissi: 3b è un byte, 3s uno short, 3L un long, 3.0f un float, 3.0d un double, [I;1,2,3] un array di int. Il pulsante di esportazione produce esattamente questo formato, trasformando un file binario in testo da incollare in un blocco comandi oppure aggiungere a git e confrontare riga per riga.

JSON non è un sostituto: dispone di un solo tipo numerico e non supporta gli array di byte, quindi la conversione da NBT a JSON perde senza avviso le distinzioni importanti per Minecraft. Per questo lo strumento esporta in SNBT anziché in JSON.

File che possono essere aperti

Qualsiasi file il cui contenuto sia un singolo documento NBT: level.dat di Java e Bedrock, playerdata, servers.dat, hotbar.nbt, idcounts.dat, raids.dat, scoreboard.dat, dati delle mappe, strutture .nbt, .schem e .schematic, .mcstructure, .litematic, contenuti estratti dei chunk e dump dei pacchetti. Da contenitori come regioni .mca, archivi .mcworld e cartelle LevelDB deve prima essere estratto un singolo documento.

Domande frequenti

Posso visualizzare un file NBT senza modificarlo?

Sì. L'editor scrive un file solo quando fai clic su Salva e scarica e non modifica mai il file che hai trascinato.

Può convertire NBT in JSON?

Esporta in SNBT, che conserva i tipi dei tag. JSON ridurrebbe byte, short, int, long e float a un unico tipo numerico e perderebbe gli array di byte, quindi non è adatto a convertire e ripristinare i dati di Minecraft senza perdite.

Perché il file viene indicato come appartenente a un'edizione diversa?

Il formato viene rilevato dai byte, non dall'estensione. Se un file viene indicato come Java quando ti aspettavi Bedrock, in genere proviene dall'altra edizione oppure è un frammento che può essere interpretato per coincidenza; controlla gli offset indicati se compare un avviso sui byte finali.

Quanto può essere grande un file da aprire?

I documenti di diversi megabyte non creano problemi: gli array vengono conservati come array tipizzati e l'albero viene generato su richiesta, quindi nella pagina esistono solo le righe espanse.
