Tutti i file NBT scritti da Minecraft

NBT (Named Binary Tag) è un formato con diverse codifiche e ogni edizione, launcher e core server di Minecraft ne usa una combinazione diversa. Questo editor le implementa tutte e sceglie quella corretta direttamente dai byte, quindi non serve conoscere la variante di un file prima di aprirlo.

Come modificare un file NBT

  1. Preleva il file dal server o dal dispositivo. I server Java lo conservano in world/, quelli Bedrock in worlds/YourWorld/, Android in games/com.mojang/minecraftWorlds/<id>/. Arresta prima il server, così il file non viene scritto mentre lo copi.
  2. Trascinalo nell'editor. L'indicatore sopra l'albero mostra cosa è stato rilevato: edizione, codifica, compressione e, per Bedrock, la versione di archiviazione dell'intestazione.
  3. Modifica. Tocca un valore per cambiarlo direttamente. Usa la ricerca per raggiungere un tag per nome o valore, + per aggiungere tag a un composto o a una lista, × per rimuoverli.
  4. Salva e scarica. I selettori del formato di uscita e della compressione usano inizialmente quelli del file originale, così una semplice modifica mantiene fedelmente il formato binario.
  5. Rimetti il file e riavvia. Conserva l'originale come backup finché il mondo non è stato caricato almeno una volta e risulta corretto.

Cosa distingue questo editor

Cinque codifiche, un'unica area

Java big-endian, Bedrock little-endian, NBT di rete Bedrock con varint, NBT di rete senza nome radice da Java 1.20.2+ e level.dat Bedrock con intestazione. Vengono rilevati, non ipotizzati.

gzip e zlib nel browser

Decompressione e ricompressione usano l'API nativa Compression Streams, quindi un level.dat Java viene restituito in un file che il gioco accetta senza modifiche di formato.

Long reali a 64 bit

I valori TAG_Long sono conservati come BigInt. I seed dei mondi e le metà degli UUID restano integri durante la modifica, invece di essere alterati dall'arrotondamento in virgola mobile che causa errori in molti strumenti NBT per browser.

Codifica corretta delle stringhe

Java scrive UTF-8 modificato (CESU-8), Bedrock usa UTF-8 standard. L'editor codifica in base all'edizione, mantenendo integri emoji e nomi dei mondi con caratteri non latini.

Adatto ai file grandi

Gli array usano array tipizzati e l'albero viene renderizzato progressivamente, 200 elementi alla volta. Un megabyte di NBT dei chunk si apre senza bloccare la scheda.

Ricerca in tutto l'albero

Trova qualsiasi tag per nome o valore in ogni punto del file e raggiungilo direttamente con il percorso espanso.

Esportazione SNBT

Esporta l'intero albero come SNBT, il formato testuale usato da /data e dai datapack, per confrontarlo, condividerlo o incollarlo in un comando.

Conversione del formato

Leggi un file Bedrock e scrivilo come Java big-endian gzip, o viceversa. Utile per protocolli, test e strumenti.

Nessun dato lascia il dispositivo

Il file viene letto con FileReader, analizzato in JavaScript e restituito come blob in memoria. Non esiste alcun endpoint di upload.

Software server supportato: tutto

NBT viene scritto dal gioco, non dall'implementazione del server, quindi ogni core che memorizza un mondo Minecraft usa una delle codifiche lette dall'editor. L'elenco completo è riportato qui sotto e non è pubblicitario: un core che scrive un mondo deve usare la struttura di Vanilla, perché il client deve poterlo leggere.

Proxy e bridge

Geyser, WaterdogPE, Waterfall, Velocity e BungeeCord non gestiscono mondi: trasferiscono NBT sulla rete. Le acquisizioni da questi socket sono NBT di rete, varint little-endian sul lato Bedrock e big-endian senza nome radice su Java 1.20.2+; entrambi si aprono direttamente qui.

Software non presente nell'elenco

Fork personalizzati, core privati, progetti didattici o un server scritto da te: se il file è NBT, l'editor rileva quale delle cinque codifiche usa e lo apre. Il funzionamento non dipende dal nome del core.

Usare il parser nel proprio codice

La pagina espone il motore in window.NBT, quindi lo stesso parser usato dall'interfaccia può essere controllato dalla console del browser o riutilizzato in uno userscript:

const bytes = new Uint8Array(await file.arrayBuffer());
const { root, format, compression, headerVersion } = await NBT.read(bytes);

root.value.find(t => t.name === "LevelName").value = "New World";

const out = await NBT.write(root, format, { compression, headerVersion });

I tag sono oggetti semplici, { type, name, value, listType }; gli array sono Int8Array, Int32Array e BigInt64Array, mentre i long sono BigInt. Il riferimento completo al formato NBT documenta ogni tipo di tag e le differenze tra le codifiche.

Domande frequenti

Questo editor NBT è gratuito?

Sì, ed è open source con licenza MIT. Non ci sono piani a pagamento, registrazione o limiti di upload, perché non esiste alcun componente server: l'intero editor è una pagina statica con due file di risorse.

Funziona con Java Edition e Bedrock Edition?

Con entrambe. I file Java Edition sono big-endian e in genere compressi con gzip; quelli Bedrock sono little-endian e level.dat contiene un'intestazione aggiuntiva di 8 byte. L'editor rileva la variante ricevuta e la mantiene al salvataggio.

Il file del mio mondo viene caricato online?

No. Il file viene letto localmente con l'API FileReader e il download è prodotto da un blob in memoria. Dopo il caricamento della pagina puoi disconnetterti dalla rete e continuare a usarla.

Posso usarlo su Android o iOS?

Sì. Il layout è progettato per dispositivi mobili, con controlli di 44 px e una barra delle azioni fissa. Su Android puoi scegliere un file del mondo direttamente da un file manager; su iOS deve prima trovarsi nell'app File a causa del sandboxing.

Qual è la differenza tra NBT e SNBT?

NBT è la codifica binaria salvata da Minecraft su disco. SNBT è la sua forma testuale, cioè la sintassi usata in comandi come /data merge. Questo editor legge NBT binario ed esporta SNBT, facilitando il confronto tra file o l'inserimento di una struttura in un comando.

Quali strumenti può sostituire?

Gli editor NBT desktop come NBTExplorer e i vari strumenti web dedicati a una sola edizione. Consulta il confronto con NBTExplorer online per vedere quali funzioni sono disponibili e quali no.
