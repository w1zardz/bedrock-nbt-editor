NBTExplorer è l'editor desktop di tag noto alla maggior parte dei giocatori di Minecraft e richiede .NET o Mono, un download e un computer. Questa pagina svolge lo stesso compito — albero dei tag, modifica diretta, aggiunta e rimozione dei tag — nel browser, su qualsiasi sistema operativo, telefoni compresi. Legge inoltre i file Bedrock little-endian, non supportati da NBTExplorer.

In sintesi: se devi esplorare un'intera cartella di regioni e aprire i chunk in base alle coordinate, lo strumento desktop resta più adatto. Se devi aprire un singolo file — un level.dat, un file giocatore, uno schematic o un mondo Bedrock — su qualunque dispositivo tu stia usando, questa soluzione è più rapida e copre edizioni mai supportate dallo strumento desktop.

Passaggio dallo strumento desktop

  • L'albero funziona nello stesso modo. Espandi compound ed elenchi, fai clic su un valore per modificarlo e usa + e × per cambiare la struttura.
  • I tipi vengono applicati nello stesso modo. Un byte resta un byte; i valori fuori intervallo vengono rifiutati invece di essere troncati senza avviso.
  • Il salvataggio produce un download, non una scrittura diretta. Il file caricato non viene mai modificato, quindi l'originale resta disponibile come backup.
  • La compressione viene mantenuta. Un file gzip viene riscritto in gzip, così il gioco lo accetta senza una ricompressione manuale.
  • Bedrock funziona direttamente. Non servono uno strumento separato né un editor esadecimale per correggere la lunghezza dell'intestazione dopo una modifica.

Quando servono ancora altri strumenti

Usa NBTExplorer o NBTStudio per esplorare molte regioni. Usa Amulet o MCA Selector per intervenire sui singoli chunk e ridurre i mondi. Usa WorldEdit per le operazioni geometriche. Usa questa pagina quando devi «aprire un file, cambiare questi tag e riaverlo» — il caso più comune — oppure quando il file è Bedrock e gli strumenti desktop non lo accettano.

Domande frequenti

Esiste una versione web ufficiale di NBTExplorer?

No. NBTExplorer è un'applicazione desktop; questo è un editor indipendente che svolge nel browser le stesse operazioni comuni e aggiunge il supporto per Bedrock.

Funziona su macOS e Linux senza Mono?

Sì: è una pagina web. Funziona con qualsiasi browser aggiornato su macOS, Linux, Windows, Android o ChromeOS.

Può aprire un'intera regione come NBTExplorer?

No. Modifica un solo documento NBT alla volta. Estrai prima un chunk dal file .mca, poi trascina qui il payload.

È sicuro usarlo sull'unico salvataggio disponibile?

Non scrive mai nel file aperto: le modifiche vengono scaricate come nuovo file. Conserva comunque un backup, come con qualsiasi editor.
