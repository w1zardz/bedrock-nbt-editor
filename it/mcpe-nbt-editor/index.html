Bedrock Edition scrive NBT in little-endian e antepone a level.dat un'intestazione di 8 byte contenente la versione di archiviazione e la lunghezza del payload. Trascina qui sotto un file Bedrock, come level.dat, .mcstructure, un valore LevelDB o un dump di protocollo: l'editor lo legge, mantiene intatta l'intestazione, ricalcola la lunghezza al salvataggio e restituisce il file pronto per la cartella del mondo.

L'intestazione di 8 byte e la sua funzione

Un level.dat Bedrock non è NBT grezzo. I primi quattro byte contengono una versione di archiviazione little-endian (8 e 10 sono i valori in uso), i quattro successivi la lunghezza in byte del payload NBT, seguiti dai tag non compressi. Se modifichi il payload senza correggere la lunghezza, il gioco rifiuta il file: è quanto accade quando si aprono salvataggi Bedrock con uno strumento NBT solo per Java.

OffsetDimensioneCampo
04 byteVersione di archiviazione, int little-endian
44 byteLunghezza del payload in byte, unsigned little-endian
8restoNBT little-endian, composto radice, non compresso

L'editor mostra la versione di archiviazione nella barra del file, la conserva e riscrive la lunghezza a ogni salvataggio.

Tag Bedrock da conoscere

Bedrock conserva le impostazioni direttamente nella radice di level.dat, invece di annidarle sotto un composto Data come Java; inoltre le regole di gioco sono tag singoli anziché figli di GameRules.

TagTipoSignificato
LevelNameStringNome del mondo mostrato nell'elenco e nell'output del server
GameTypeInt0 sopravvivenza, 1 creativa, 2 avventura
DifficultyInt0 pacifica … 3 difficile
commandsEnabledByteTrucchi attivi o disattivati
SpawnX, SpawnY, SpawnZIntSpawn del mondo
RandomSeedLongSeed del mondo, un vero valore a 64 bit
lastOpenedWithVersionElenco di IntBuild del client o server che ha scritto il mondo per ultimo
StorageVersionIntRevisione dell'archiviazione del mondo, corrispondente all'intestazione
experimentsCompoundOpzioni sperimentali abilitate per il mondo
keepinventory, domobspawning, …ByteRegole di gioco, ciascuna in un tag minuscolo

Trovare il file su ogni piattaforma

  • Android: Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/<id>/level.dat. Le versioni recenti di Android limitano l'accesso alla cartella: usa l'esportazione del mondo nel gioco oppure un file manager con le autorizzazioni necessarie.
  • iOS: esporta il mondo dal gioco in un file .mcworld, aprilo nell'app File e decomprimilo: level.dat si trova nella radice dell'archivio.
  • Windows: %LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\<id>\level.dat.
  • Bedrock Dedicated Server: worlds/<World>/level.dat.
  • PocketMine-MP, Nukkit, PowerNukkitX: worlds/<World>/level.dat: consulta la guida lato server.

Il nome della cartella del mondo è un id casuale, non il nome del mondo. Ordina le cartelle per data di modifica oppure apri qui alcuni file level.dat e leggi LevelName per individuare quello corretto.

Oltre level.dat

Bedrock conserva chunk, entità ed entità blocco in un database LevelDB nella cartella db/, usando NBT little-endian come valore di molte chiavi. Estrai un valore per aprirlo qui come Bedrock senza intestazione, senza intestazione né compressione. I file struttura usano la stessa codifica: consulta l'editor .mcstructure. Le acquisizioni del protocollo usano la variante varint, rilevata dall'editor come Bedrock di rete.

Domande frequenti

Perché il mio level.dat Bedrock non si apre in NBTExplorer?

Perché NBTExplorer si aspetta la struttura big-endian di Java e non riconosce l'intestazione Bedrock di 8 byte. Questo editor gestisce entrambe e riscrive la lunghezza nell'intestazione al salvataggio.

Posso modificare un mondo MCPE sul telefono?

Sì. Apri questa pagina nel browser del telefono, scegli il file dal file manager, modificalo e salvalo. Il file scaricato si trova nella cartella Download; copialo al posto dell'originale.

Qual è la differenza tra la versione di archiviazione 8 e 10?

Indicano revisioni del formato di archiviazione dei mondi Bedrock; 10 è quella scritta dai client attuali. L'editor mantiene il valore presente nel file invece di forzarne uno, perché riscriverlo non migra i dati del mondo.

Funziona con i file .mcworld?

Non direttamente: un .mcworld è un archivio zip. Decomprimilo, modifica qui level.dat, reinseriscilo nell'archivio e rinomina di nuovo il file come .mcworld.

Funziona con le regole di gioco Bedrock?

Sì. Bedrock conserva ogni regola come un tag byte minuscolo nella radice, ad esempio keepinventory, domobspawning e showcoordinates. Imposta il byte su 1 o 0. La guida alle regole di gioco le elenca.
