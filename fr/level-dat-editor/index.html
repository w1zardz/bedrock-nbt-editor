Éditeur level.dat — paramètres d'un monde Minecraft

Compatible avec Minecraft Bedrock Edition et Java Edition, ainsi qu'avec tous leurs logiciels serveur, courants ou non : Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina et les autres. Liste complète.

level.dat contient tout ce qu'un monde Minecraft sait de lui-même : son nom, son mode de jeu, sa difficulté, son point d'apparition, ses règles de jeu, son état météorologique et la dernière version qui l'a ouvert. Déposez-le ci-dessous pour modifier directement ces valeurs. Les fichiers Java (gzip, gros-boutistes) et Bedrock (petit-boutistes avec un en-tête de 8 octets) sont pris en charge et réécrits dans leur format d'origine.

Minecraft écrit également un level.dat_old à côté : il s'agit de la sauvegarde précédente. Ce fichier s'ouvre aussi dans cet éditeur et constitue le premier recours si le fichier actuel ne se charge pas.

Modifier le fichier sans risque

  • Arrêtez d'abord le serveur ou fermez le jeu. Minecraft réécrit level.dat pendant les sauvegardes automatiques et à l'arrêt. Un serveur actif écrasera votre modification ou, pire, écrira sur un fichier copié en partie.
  • Conservez l'original. Cet éditeur ne modifie jamais le fichier déposé ; il produit un nouveau téléchargement. Gardez l'ancienne copie jusqu'au premier chargement réussi du monde.
  • Ne changez pas le type des balises. Remplacer le type Byte de Difficulty par Int ou renommer une balise attendue par Minecraft peut empêcher le chargement du monde. Modifiez les valeurs, pas la structure, sauf si vous maîtrisez la raison du changement.
  • Préservez l'en-tête Bedrock. L'en-tête de 8 octets contient la version de stockage et la longueur de la charge utile. L'éditeur met automatiquement la longueur à jour et conserve la version ; un fichier modifié à la main qui perd cet en-tête ne se chargera pas.

Questions fréquentes

Puis-je modifier level.dat sans télécharger de logiciel ?

Oui, c'est précisément le rôle de cette page. L'analyseur s'exécute dans votre navigateur : rien n'est à installer, et seul un navigateur récent est nécessaire.

Pourquoi mon monde affiche-t-il encore l'ancien nom ?

Le nom affiché dans la liste des mondes provient de LevelName dans level.dat, et non du nom du dossier. Copier ou renommer le dossier ne change pas cette balise. Modifiez-la pour actualiser la liste.

L'éditeur fonctionne-t-il avec level.dat_old ?

Oui. level.dat_old est la sauvegarde précédente, dans le même format. Si le fichier actuel est endommagé, ouvrez la copie _old, vérifiez son contenu, puis restaurez-la sous le nom d'origine.

Puis-je changer la graine du monde ici ?

Vous pouvez modifier la balise de la graine, mais cela ne concerne que le terrain généré après le changement. Les chunks déjà enregistrés conservent leur forme ; la jonction entre l'ancien et le nouveau terrain sera donc visible.

Modifier level.dat peut-il entraîner un bannissement ou endommager mon monde ?

Il s'agit de votre propre sauvegarde, donc aucun bannissement n'est possible. Les dommages surviennent si vous modifiez le fichier pendant que le serveur fonctionne, ou si vous changez le type et le nom des balises plutôt que leurs valeurs. Arrêtez le serveur et gardez une sauvegarde.
