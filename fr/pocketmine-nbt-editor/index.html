The duplicated-world-name problem

Every Bedrock server admin hits this. You copy worlds/hub to worlds/hub2 to make a second arena, and the console, the world manager and every plugin that reports a world name keep calling both of them hub. The folder name changed; LevelName inside level.dat did not.

The consequences are not cosmetic. Plugins that look worlds up by their internal name — teleport pads, per-world configs, region protection — can resolve to the wrong world, and world-management commands become ambiguous. Fix it by editing the tag: drop the file above and the editor jumps straight to LevelName and opens it for editing.

  1. Stop the server. A running server rewrites level.dat on save and will undo the edit.
  2. Download worlds/<World>/level.dat over SFTP or from your panel's file manager.
  3. Drop it into the editor, change LevelName to the new name, save.
  4. Upload it back over the original, keeping the old file as a backup.
  5. Start the server and check the console line that reports loaded worlds.

Doing it without breaking production

  • Back up the whole world folder, not just level.dat. It costs seconds and it is the only thing that makes a bad edit reversible.
  • Never edit a live file over SFTP. Download, edit, upload while the server is stopped. Editing in place while the server holds the world open is how you end up with a truncated file.
  • Copying a world for a new mode? Change LevelName immediately after copying, before the server sees it, so nothing ever caches the wrong name.
  • Check the file bar after loading. It shows the detected format and the storage version — if a Bedrock file is reported as anything but Bedrock level.dat, you grabbed the wrong file or it is corrupt.

Frequently Asked Questions

Does PocketMine-MP use the same level.dat as Bedrock?

Yes. PocketMine-MP implements the Bedrock world format, so its level.dat is little-endian NBT with the 8-byte header, byte-for-byte the same shape the vanilla Bedrock server writes.

Why do two worlds show the same name in console?

Because both were copied from one folder and share a LevelName. The folder name and the tag are independent; change the tag.

Can I rename a world without restarting the server?

No. The world is loaded in memory and rewritten on save, so an edit made while it is running is discarded. Stop, edit, start.

Does this work with Nukkit and PowerNukkitX?

Yes — same format, same file path, same procedure.

How do I convert a Bedrock world to Java?

Not with an NBT editor. Byte order is the easy part; the tag layout, block palettes and chunk storage differ completely. Use a purpose-built converter, then use this editor for the leftover metadata.
