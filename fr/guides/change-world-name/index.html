Changer le nom d'un monde Minecraft

Compatible avec Minecraft Bedrock Edition et Java Edition, ainsi qu'avec tous leurs logiciels serveur, courants ou non : Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina et les autres. Liste complète.

Le nom affiché d'un monde se trouve dans la balise LevelName de level.dat, pas dans le nom du dossier. Renommer le dossier ne change rien à l'affichage du jeu ; c'est pourquoi un monde copié continue d'annoncer son nom d'origine. Déposez level.dat dans l'éditeur ci-dessous : il accède directement à LevelName. Modifiez la valeur, enregistrez, puis remettez le fichier en place.

Pourquoi renommer le dossier ne change rien

Minecraft considère le dossier comme une adresse et LevelName comme une étiquette. La liste des mondes, la console du serveur, les plugins de gestion des mondes et tout composant qui affiche « world » dans le chat lisent cette balise. La copie d'un dossier — cp -r worlds/hub worlds/hub2 — produit donc deux mondes qui se présentent tous deux comme hub. La seule correction se trouve dans le fichier.

Sur un serveur, ce doublon est plus qu'une source de confusion. Les plugins qui retrouvent les mondes par leur nom interne peuvent intervenir sur le mauvais : téléporteurs, configurations par monde, régions protégées, multiplicateurs économiques. Renommez la balise dès la copie du monde, avant qu'un composant ne la mette en cache.

Selon la plateforme

Java en solo

Le client propose de renommer le monde dans l'écran des options et modifie LevelName pour vous. La modification manuelle du fichier est utile lorsque le monde ne se charge pas, lorsque vous travaillez sur une copie ou lorsque le dossier et le nom affiché doivent volontairement différer.

Serveur Java

level-name dans server.properties sélectionne le dossier à charger. Il ne renomme rien. Modifiez LevelName dans world/level.dat pour changer le nom affiché.

Bedrock et MCPE

L'écran de modification du monde intégré au jeu permet de le renommer. Si le monde se trouve sur un serveur ou si vous corrigez un fichier .mcworld exporté, modifiez directement LevelName dans level.dat. Bedrock place cette balise directement à la racine, sans compression, derrière l'en-tête de 8 octets que l'éditeur gère automatiquement.

Serveurs Bedrock (PocketMine-MP, Nukkit, BDS)

Même fichier, même balise et même obligation d'arrêter d'abord le serveur. La page consacrée aux serveurs décrit toute la procédure, y compris la copie du dossier.

Si le nom ne change pas

  • Le serveur fonctionnait. Sa copie en mémoire a remplacé votre fichier lors de la sauvegarde suivante. Arrêtez-le et recommencez.
  • Vous avez modifié le mauvais monde. Les dossiers de mondes Bedrock portent des identifiants aléatoires. Ouvrez le fichier et lisez LevelName pour confirmer le monde avant toute modification.
  • Vous avez modifié level.dat_old. Il s'agit de la sauvegarde précédente, pas du fichier actif.
  • Un lanceur ou un panneau met le nom en cache. Certains panneaux d'hébergement affichent un nom provenant de leur propre base de données plutôt que du fichier du monde ; le nom affiché par le jeu sera correct.
  • Le monde ne se charge plus du tout. Restaurez la sauvegarde et consultez le guide pour réparer un level.dat endommagé.

Questions fréquentes

Renommer un monde supprime-t-il des données ?

Non. LevelName est une étiquette. Le terrain, les joueurs, les inventaires et les entités se trouvent dans d'autres fichiers et ne sont pas modifiés.

Puis-je utiliser des espaces, des couleurs ou des emoji dans le nom ?

Les espaces sont acceptés. Les codes de couleur avec le signe section fonctionnent sur certains logiciels serveur et s'affichent littéralement ailleurs. Les emoji résistent à l'aller-retour ici, car l'éditeur utilise le bon encodage de chaînes pour chaque édition, mais les consoles et journaux peuvent mal les afficher.

Dois-je aussi renommer le dossier ?

Non, et il vaut souvent mieux l'éviter : le paramètre level-name d'un serveur ou la configuration d'un plugin peut viser le chemin du dossier. Ne modifiez qu'un élément à la fois.

Les joueurs verront-ils immédiatement le nouveau nom ?

Oui, après le rechargement du monde. Les clients qui ont mis en cache une entrée de la liste des serveurs peuvent nécessiter une actualisation.
