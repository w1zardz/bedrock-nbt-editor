A .mcstructure é um arquivo NBT little-endian sem compressão gravado por um bloco de estrutura Bedrock. Solte-o abaixo para ler tamanho, paleta, índices e entidades de bloco, editar os dados e baixar na mesma codificação, sem reabrir o mundo.

O que há em um .mcstructure

TagTipoO que contém
format_versionIntRevisão do formato da estrutura; 1 nos arquivos atuais
sizeLista de IntDimensões X, Y e Z do volume capturado
structure_world_originLista de IntLocal onde a estrutura foi capturada no mundo
structureCompoundTodos os dados abaixo ficam aqui
structure.block_indicesLista de Int[]Duas camadas de índices da paleta, normalmente blocos e waterlogging; -1 significa “mantenha o que já está no local”
structure.entitiesLista de CompoundEntidades capturadas com a estrutura
structure.palette.default.block_paletteLista de CompoundCada estado de bloco distinto: name, states, version
structure.palette.default.block_position_dataCompoundNBT da entidade de bloco indexado pela posição linear

Os índices em block_indices percorrem X, depois Z e Y; um índice linear de (x * sizeZ + z) * sizeY + y na lista da paleta. Esse mapeamento permite corrigir um único bloco sem recriar a estrutura.

Alterações comuns

  • Trocar um tipo de bloco em toda a estrutura editando uma entrada em block_palette; todas as posições que apontam para esse índice mudam juntas.
  • Corrigir um estado de bloco como um facing incorreto ou um waterlogged acidental no compound states.
  • Remover entidades capturadas por engano, removendo entradas da lista entities.
  • Corrigir dados de entidades de bloco, como inventário de baú, texto de placa e configurações de spawner, em block_position_data.
  • Conferir a versão nas entradas da paleta quando uma atualização faz a estrutura importar blocos errados.

Onde ficam os arquivos

Blocos de estrutura salvam na pasta structures/ do diretório do mundo, em arquivos chamados <namespace>_<name>.mcstructure. Pacotes de comportamento os incluem em structures/ no pacote, onde o jogo os carrega por namespace. Ambos usam o mesmo formato e abrem aqui.

O equivalente da Java Edition é o arquivo de estrutura .nbt big-endian com gzip, com outra codificação e estrutura de tags. A página do editor Java explica esses arquivos, que também abrem neste editor.

Perguntas frequentes

Posso converter .mcstructure para uma estrutura .nbt Java?

O editor pode recodificar os bytes para big-endian com gzip, mas a estrutura das tags é diferente. Estruturas Java usam palette/blocks com outras chaves e nomes de blocos. Um arquivo recodificado é legível, mas não é uma estrutura Java válida.

Por que meu .mcstructure não está compactado?

O Bedrock grava estruturas como NBT little-endian bruto, sem gzip. Isso é normal; o editor detecta como Bedrock bruto.

O que significa o índice -1 em block_indices?

Ele marca uma posição que a estrutura não altera; o bloco existente no mundo é mantido ao colocar a estrutura.

Posso redimensionar uma estrutura editando size?

Não apenas com isso. block_indices tem uma entrada por posição; o tamanho do array deve corresponder exatamente ao novo volume. Alterar size sozinho gera um arquivo recusado pelo jogo.
