Todos os arquivos NBT gravados pelo Minecraft

NBT (Named Binary Tag) é um formato com várias codificações, e cada edição, launcher e software de servidor do Minecraft usa uma combinação diferente. Este editor implementa todas elas e identifica a correta pelos próprios bytes, sem exigir que você saiba a variante do arquivo antes de abri-lo.

Como editar um arquivo NBT

  1. Copie o arquivo do servidor ou dispositivo. Servidores Java o mantêm em world/, servidores Bedrock em worlds/YourWorld/ e Android em games/com.mojang/minecraftWorlds/<id>/. Primeiro pare o servidor para que o arquivo não seja gravado durante a cópia.
  2. Solte-o no editor. O indicador acima da árvore mostra o que foi detectado: edição, codificação, compressão e, no Bedrock, a versão de armazenamento do cabeçalho.
  3. Edite. Toque em um valor para alterá-lo. Use a busca para ir a uma tag pelo nome ou valor, + para adicionar tags a qualquer compound ou lista e × para removê-las.
  4. Salve e baixe. Os seletores de formato de saída e compressão mantêm por padrão as opções do arquivo original, preservando o formato em uma edição simples.
  5. Recoloque o arquivo e reinicie. Guarde o original como backup até o mundo carregar uma vez e parecer correto.

O que diferencia este editor

Cinco codificações, uma área de envio

Java big-endian, Bedrock little-endian, NBT de rede Bedrock com varint, NBT de rede Java 1.20.2+ com raiz sem nome e level.dat do Bedrock com cabeçalho. O formato é detectado, não presumido.

gzip e zlib no navegador

A descompressão e a recompressão usam a API nativa Compression Streams; assim, um level.dat Java é salvo em um arquivo aceito pelo jogo sem alterações de formato.

Longs reais de 64 bits

TAG_Long são mantidos como BigInt. Seeds de mundo e metades de UUID permanecem exatos após a edição, sem a distorção do arredondamento de ponto flutuante que afeta muitas ferramentas NBT no navegador.

Codificação correta de strings

Java grava UTF-8 modificado (CESU-8), enquanto Bedrock usa UTF-8 padrão. O editor codifica conforme a edição, preservando emojis e nomes de mundos com caracteres não latinos.

Preparado para arquivos grandes

Arrays usam arrays tipados e a árvore é renderizada sob demanda, 200 entradas por vez. Um megabyte de NBT de chunk abre sem travar a aba.

Busca em toda a árvore

Encontre qualquer tag por nome ou valor em todo o arquivo e vá diretamente a ela com o caminho expandido.

Exportação de SNBT

Exporte toda a árvore como SNBT, o formato textual usado por /data e datapacks, para comparar, compartilhar ou colar em um comando.

Conversão de formato

Leia um arquivo Bedrock e grave em Java big-endian com gzip, ou faça o inverso. Útil para protocolos, testes e ferramentas.

Nada sai do seu dispositivo

O arquivo é lido com FileReader, processado em JavaScript e devolvido como um blob na memória. Não existe endpoint de upload.

Softwares de servidor compatíveis

O NBT é gravado pelo jogo, não pela implementação do servidor. Portanto, qualquer software que armazene um mundo do Minecraft usa uma das codificações lidas por este editor. A lista abaixo é técnica: um servidor que grava um mundo usa a estrutura do Vanilla, pois o cliente precisa lê-la.

Bedrock Edition — NBT little-endian, level.dat com cabeçalho de 8 bytes

Bedrock Dedicated Server (BDS), PocketMine-MP (PM3, PM4, PM5), Nukkit, Nukkit-MOT, PowerNukkitX, Cloudburst Server, Dragonfly, Endstone, LeviLamina e BDSX, Allay, JukeboxMC, GoMint, Sculk, ElementZero, LiteLoaderBDS, além dos MCPE e MCBE nos próprios clientes para Android, iOS, Windows, consoles e Switch. O mesmo worlds/<World>/level.dat, o mesmo cabeçalho e as mesmas tags; consulte o procedimento para servidores.

Java Edition — NBT big-endian, gzip

Vanilla, CraftBukkit, Spigot, Paper, Purpur, Pufferfish, Folia, Leaves, Gale, Petal, Airplane, Sponge (SpongeVanilla, SpongeForge), Fabric, Quilt, Forge, NeoForge, Mohist, Arclight, Magma, Ketting, Banner, Cardboard, Glowstone, Thermos, Uberbukkit e qualquer outro fork, servidor de modpack ou versão legada. Se grava world/level.dat, este editor o abre; veja os detalhes.

Proxies e pontes

Geyser, WaterdogPE, Waterfall, Velocity e BungeeCord não armazenam mundos; eles transportam NBT pela rede. Capturas desses sockets são NBT de rede: varint little-endian no lado Bedrock e big-endian com raiz sem nome no Java 1.20.2+. Ambos abrem diretamente aqui.

Qualquer software fora da lista

Forks personalizados, softwares privados, projetos didáticos ou um servidor criado por você: se o arquivo for NBT, o editor detecta qual das cinco codificações ele usa e o abre. Nada depende do nome do software.

Use o parser no seu próprio código

A página expõe seu mecanismo em window.NBT; assim, o mesmo parser da interface pode ser controlado pelo console do navegador ou reutilizado em um userscript:

const bytes = new Uint8Array(await file.arrayBuffer());
const { root, format, compression, headerVersion } = await NBT.read(bytes);

root.value.find(t => t.name === "LevelName").value = "New World";

const out = await NBT.write(root, format, { compression, headerVersion });

As tags são objetos simples: { type, name, value, listType }; os arrays são Int8Array, Int32Array e BigInt64Array; e os longs são BigInt. A referência do formato NBT documenta todos os tipos de tag e as diferenças entre codificações.

Perguntas frequentes

Este editor NBT é gratuito?

Sim. Ele é gratuito e tem código aberto sob a licença MIT. Não há plano pago, cadastro nem cota de upload, pois não existe componente de servidor: o editor é uma página estática com dois arquivos de recursos.

Funciona com Java Edition e Bedrock Edition?

Com ambas. Arquivos da Java Edition são big-endian e geralmente compactados com gzip; arquivos Bedrock são little-endian, e level.dat inclui um cabeçalho extra de 8 bytes. O editor detecta a variante recebida e grava a mesma ao salvar.

Meu arquivo de mundo é enviado para algum lugar?

Não. O arquivo é lido localmente pela API FileReader, e o download é gerado de um blob na memória. Depois que a página carregar, você pode desconectar a rede e continuar usando o editor.

Posso usar no Android ou iOS?

Sim. O layout prioriza dispositivos móveis, com áreas de toque de 44 px e barra de ações fixa. No Android, escolha o mundo no gerenciador de arquivos; no iOS, coloque-o primeiro no app Arquivos devido ao isolamento do sistema.

Qual é a diferença entre NBT e SNBT?

NBT é a codificação binária que o Minecraft armazena em disco. SNBT é sua forma textual, usada em comandos como /data merge. Este editor lê NBT binário e exporta SNBT, facilitando a comparação de arquivos ou a inserção de uma estrutura em um comando.

Quais ferramentas ele substitui?

Editores NBT para desktop, como NBTExplorer, e ferramentas web específicas que aceitam apenas uma edição. Consulte a comparação com o NBTExplorer on-line para ver quais recursos estão disponíveis.
