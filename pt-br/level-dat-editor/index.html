level.dat é o arquivo que contém as informações do próprio mundo do Minecraft: nome, modo de jogo, dificuldade, ponto de spawn, regras, clima e última versão usada. Solte-o abaixo para editar esses valores. Arquivos Java (gzip, big-endian) e Bedrock (little-endian com cabeçalho de 8 bytes) são aceitos e gravados no formato original.

As tags mais editadas

Um level.dat Java mantém quase tudo em um único compound Data; um level.dat Bedrock mantém as tags diretamente na raiz. Os nomes abaixo são os mais úteis: procure qualquer um deles na árvore para ir até a tag.

O Minecraft também grava level.dat_old ao lado dele: é o save anterior. Esse arquivo também abre no editor e deve ser a primeira opção se o arquivo atual não carregar.

Edição segura

  • Primeiro pare o servidor ou feche o jogo. O Minecraft regrava level.dat no salvamento automático e ao encerrar. Um servidor em execução sobrescreverá a edição ou até um arquivo copiado pela metade.
  • Guarde o original. O editor não modifica o arquivo enviado; ele gera um novo download. Mantenha a cópia antiga até o mundo carregar uma vez.
  • Não altere os tipos das tags. Alterar Difficulty de Byte para Int ou renomear uma tag esperada pelo Minecraft pode impedir o carregamento. Edite valores, não a estrutura, a menos que saiba o motivo.
  • Mantenha o cabeçalho Bedrock intacto. O cabeçalho de 8 bytes contém a versão de armazenamento e o tamanho dos dados. O editor recalcula o tamanho e preserva a versão; arquivos sem esse cabeçalho não carregam.

Perguntas frequentes

Posso editar level.dat sem instalar programas?

Sim. O parser é executado no navegador; não há nada para instalar nem requisito de sistema além de um navegador atual.

Por que meu mundo ainda mostra o nome antigo?

Porque o nome na lista de mundos vem de LevelName dentro de level.dat, não do nome da pasta. Copiar ou renomear a pasta não altera a tag. Edite-a para atualizar a lista.

Funciona com level.dat_old?

Sim. level.dat_old é o save anterior no mesmo formato. Se o arquivo atual estiver corrompido, abra a cópia _old, confira os dados e restaure-a com o nome original.

Posso alterar a seed do mundo aqui?

Você pode editar a tag da seed, mas isso só afeta terrenos gerados depois da alteração. Chunks já salvos mantêm o formato antigo, deixando visível a junção entre os terrenos.

Editar level.dat pode causar banimento ou corromper o mundo?

É seu próprio arquivo de save, portanto não há motivo para banimento. A corrupção ocorre ao editar com o servidor ligado ou alterar tipos e nomes de tags. Pare o servidor, edite valores e mantenha um backup.
