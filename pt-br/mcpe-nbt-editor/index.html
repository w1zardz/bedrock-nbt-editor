O cabeçalho de 8 bytes e sua função

Um level.dat Bedrock não é NBT bruto. Os quatro primeiros bytes são a versão de armazenamento little-endian (normalmente 8 ou 10); os quatro seguintes indicam o tamanho dos dados NBT; depois vêm as tags sem compressão. Se o tamanho não for atualizado, o jogo rejeita o arquivo, como ocorre ao usar ferramentas exclusivas para Java.

OffsetTamanhoCampo
04 bytesVersão de armazenamento, Int little-endian
44 bytesTamanho dos dados em bytes, inteiro sem sinal little-endian
8restanteNBT little-endian, compound raiz, sem compressão

O editor mostra a versão de armazenamento na barra do arquivo, preserva-a e recalcula o tamanho sempre que você salva.

Tags Bedrock importantes

O Bedrock mantém as configurações diretamente na raiz de level.dat em vez de agrupá-las em um compound Data como no Java. As regras de jogo são tags individuais, não um filho GameRules.

TagTipoSignificado
LevelNameStringNome exibido na lista de mundos e na saída do servidor
GameTypeInt0 sobrevivência, 1 criativo, 2 aventura
DifficultyInt0 pacífico … 3 difícil
commandsEnabledByteCheats ativados ou desativados
SpawnX, SpawnY, SpawnZIntSpawn do mundo
RandomSeedLongSeed do mundo, um valor real de 64 bits
lastOpenedWithVersionLista de IntBuild do cliente ou servidor que gravou o mundo por último
StorageVersionIntRevisão de armazenamento do mundo, igual ao cabeçalho
experimentsCompoundOpções experimentais ativadas no mundo
keepinventory, domobspawning, …ByteRegras de jogo, uma tag minúscula para cada regra

Como localizar o arquivo em cada plataforma

  • Android: Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/<id>/level.dat. Versões recentes do Android restringem essa pasta; use a exportação de mundos do jogo ou um gerenciador com a permissão necessária.
  • iOS: exporte o mundo como .mcworld pelo jogo, abra-o no app Arquivos e descompacte-o; level.dat fica na raiz do arquivo.
  • Windows: %LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\<id>\level.dat.
  • Bedrock Dedicated Server: worlds/<World>/level.dat.
  • PocketMine-MP, Nukkit, PowerNukkitX: worlds/<World>/level.dat; consulte o guia para servidores.

O nome da pasta do mundo é um ID aleatório, não o nome do mundo. Ordene por data de modificação ou abra alguns level.dat neste editor e leia LevelName para identificar o correto.

Além do level.dat

O Bedrock armazena chunks, entidades e entidades de bloco em um banco LevelDB na pasta db/, usando NBT little-endian como valor de muitas chaves. Extraia um valor para abri-lo aqui como Bedrock bruto — sem cabeçalho nem compressão. Arquivos de estrutura usam a mesma codificação; consulte o editor de .mcstructure. Capturas de protocolo usam a variante varint, detectada como rede Bedrock.

Perguntas frequentes

Por que meu level.dat Bedrock não abre no NBTExplorer?

Porque o NBTExplorer espera o formato big-endian do Java e não reconhece o cabeçalho Bedrock de 8 bytes. Este editor aceita ambos e recalcula o tamanho no cabeçalho.

Posso editar um mundo MCPE no celular?

Sim. Abra esta página no navegador do celular, escolha o arquivo no gerenciador, edite e salve. O download ficará na pasta Downloads; copie-o sobre o original.

Qual é a diferença entre as versões de armazenamento 8 e 10?

Elas indicam revisões do formato de armazenamento Bedrock; clientes atuais usam 10. O editor mantém o valor original, pois alterá-lo não migra os dados do mundo.

Funciona com arquivos .mcworld?

Não diretamente. Um .mcworld é um arquivo ZIP. Descompacte-o, edite level.dat aqui, recoloque-o no arquivo e renomeie-o de volta para .mcworld.

Funciona com regras de jogo do Bedrock?

Sim. O Bedrock armazena cada regra como uma tag Byte minúscula na raiz, como keepinventory, domobspawning, showcoordinates e outras. Defina o Byte como 1 ou 0. O guia de regras de jogo lista todas elas.
