NBTExplorer онлайн — альтернатива у браузері

Підтримуються Minecraft Bedrock Edition і Java Edition — а також усі їхні серверні ядра, популярні й маловідомі: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina та інші. Повний список.

NBTExplorer — відомий гравцям Minecraft настільний редактор тегів, якому потрібні .NET або Mono, завантаження та комп’ютер. Ця сторінка виконує ті самі завдання — дерево тегів, редагування значень, додавання й видалення тегів — у браузері на будь-якій операційній системі, зокрема на телефонах. Вона також читає файли Bedrock little-endian, які NBTExplorer не підтримує.

Якщо потрібно переглядати всю папку регіону й відкривати чанки за координатами, настільний інструмент зручніший. Якщо треба відкрити один файл — level.dat, файл гравця, схему або світ Bedrock — на доступному пристрої, ця сторінка працює швидше й підтримує видання, яких немає в настільному інструменті.

Перехід із настільного інструмента

  • Дерево працює так само. Розгортайте compound і списки, натискайте значення для редагування, використовуйте + і × для зміни структури.
  • Типи перевіряються так само. Byte залишається byte; значення поза діапазоном відхиляються, а не непомітно обрізаються.
  • Збереження створює завантаження, а не змінює файл на місці. Перетягнутий файл залишається недоторканим, тому оригінал зберігається автоматично.
  • Стиснення відтворюється. Файл gzip зберігається як gzip, тому гра приймає його без ручного повторного стиснення.
  • Bedrock працює одразу. Окремий інструмент або hex-редактор для виправлення довжини заголовка після змін не потрібен.

Коли потрібні інші інструменти

Використовуйте NBTExplorer або NBTStudio для масового перегляду регіонів. Amulet або MCA Selector підходять для операцій із чанками та обрізання світу. WorldEdit потрібен для геометричних змін. Ця сторінка призначена для завдання «відкрити один файл, змінити теги й отримати його назад», а також для файлів Bedrock, які настільні інструменти не приймають.

Часті запитання

Чи існує офіційна вебверсія NBTExplorer?

Ні. NBTExplorer — настільний застосунок; це незалежний редактор, який виконує ті самі повсякденні завдання у браузері та додатково підтримує Bedrock.

Чи працює він на macOS і Linux без Mono?

Так, це вебсторінка. Достатньо сучасного браузера на macOS, Linux, Windows, Android або ChromeOS.

Чи можна відкрити цілий файл регіону, як у NBTExplorer?

Ні. Редактор обробляє один документ NBT за раз. Спочатку вилучіть чанк із .mca, а потім перетягніть сюди його дані.

Чи безпечно використовувати його для єдиного збереження?

Редактор не записує у відкритий файл: зміни повертаються як нове завантаження. Проте, як і під час роботи з будь-яким редактором, зберігайте власну резервну копію.
