Редактор level.dat для PocketMine-MP і Bedrock Server

Підтримує Minecraft Bedrock Edition і Java Edition — а також усі популярні й маловідомі серверні ядра для обох версій: Vanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, Mohist, Sponge, Bedrock Dedicated Server, PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly, Endstone, LeviLamina та інші. Повний список.

Серверне програмне забезпечення Bedrock — PocketMine-MP, Nukkit, PowerNukkitX, Cloudburst, Dragonfly та офіційний Bedrock Dedicated Server — читає однаковий level.dat little-endian із 8-байтовим заголовком із worlds/<World>/. Перетягніть свій файл нижче, щоб виправити назву світу після дублювання папки, перемістити точку появи, змінити правила гри або перевірити, яка збірка востаннє записувала світ.

Проблема однакових назв світів

Із цим стикається кожен адміністратор сервера Bedrock. Ви копіюєте worlds/hub до worlds/hub2, щоб створити другу арену, але консоль, менеджер світів і кожен плагін, який показує назву світу, надалі називають обидва світи hub. Назва папки змінилася, а LevelName усередині level.dat — ні.

Наслідки не лише візуальні. Плагіни, які шукають світи за внутрішньою назвою, — точки телепортації, конфігурації окремих світів, захист регіонів — можуть вибрати неправильний світ, а команди керування світами стають неоднозначними. Виправте тег: перетягніть файл вище, після чого редактор одразу перейде до LevelName і відкриє його для редагування.

  1. Зупиніть сервер. Запущений сервер перезапише level.dat під час збереження та скасує редагування.
  2. Завантажте worlds/<World>/level.dat через SFTP або файловий менеджер панелі.
  3. Перетягніть файл до редактора, змініть LevelName на нову назву та збережіть.
  4. Завантажте його назад із заміною початкового файла, зберігши старий файл як резервну копію.
  5. Запустіть сервер і перевірте рядок консолі зі списком завантажених світів.

Як не пошкодити робочий сервер

  • Створіть резервну копію всієї папки світу, а не лише level.dat. Це займає кілька секунд і є єдиним способом скасувати невдале редагування.
  • Ніколи не редагуйте активний файл через SFTP. Завантажуйте, редагуйте та повертайте файл лише після зупинки сервера. Редагування на місці, поки сервер тримає світ відкритим, може призвести до обрізання файла.
  • Копіюєте світ для нового режиму? Змініть LevelName одразу після копіювання, до першого відкриття сервером, щоб неправильна назва ніде не потрапила до кешу.
  • Після завантаження перевірте панель файла. Вона показує визначений формат і версію сховища. Якщо файл Bedrock визначено не як Bedrock level.dat, ви вибрали не той файл або він пошкоджений.

Часті запитання

Чи використовує PocketMine-MP той самий level.dat, що й Bedrock?

Так. PocketMine-MP реалізує формат світу Bedrock, тому його level.dat — це NBT little-endian з 8-байтовим заголовком, що має точно таку саму структуру, яку записує стандартний сервер Bedrock.

Чому два світи мають однакову назву в консолі?

Тому що обидва скопійовані з однієї папки й мають однаковий LevelName. Назва папки й тег не залежать один від одного; змініть тег.

Чи можна перейменувати світ без перезапуску сервера?

Ні. Світ завантажено в пам’ять і перезаписується під час збереження, тому редагування запущеного світу буде відкинуто. Зупиніть сервер, відредагуйте файл і запустіть сервер.

Чи працює це з Nukkit і PowerNukkitX?

Так: той самий формат, той самий шлях до файла й така сама процедура.

Як перетворити світ Bedrock на Java?

Це неможливо зробити редактором NBT. Порядок байтів — найпростіша частина; структура тегів, палітри блоків і зберігання чанків повністю відрізняються. Скористайтеся спеціалізованим конвертером, а потім цим редактором для решти метаданих.
