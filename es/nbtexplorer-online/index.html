En resumen: si necesitas recorrer una carpeta de regiones y abrir chunks por coordenadas, el programa de escritorio sigue siendo mejor. Si quieres abrir un solo archivo —level.dat, datos de jugador, un esquema o un mundo Bedrock— en cualquier dispositivo, esta opción es más directa y admite más ediciones.

Si vienes del programa de escritorio

  • El árbol funciona igual. Expande compuestos y listas, pulsa un valor para editarlo y usa + y × para cambiar la estructura.
  • Los tipos se validan igual. Un byte sigue siendo byte; los valores fuera de rango se rechazan en vez de truncarse.
  • Guardar genera una descarga, no escribe sobre el archivo original. Así siempre conservas una copia.
  • Se conserva la compresión. Un archivo gzip vuelve a salir como gzip para que el juego lo acepte sin recomprimirlo manualmente.
  • Bedrock funciona directamente. No necesitas otra herramienta ni un editor hexadecimal para corregir el encabezado.

Cuándo usar otras herramientas

Usa NBTExplorer o NBTStudio para explorar regiones en lote. Usa Amulet o MCA Selector para modificar chunks y recortar mundos. Usa WorldEdit para cambios geométricos. Usa esta página cuando necesites "abrir un archivo, cambiar etiquetas y devolverlo", o si las herramientas de escritorio rechazan un archivo de Bedrock.

Preguntas frecuentes

¿Existe una versión web oficial de NBTExplorer?

No. NBTExplorer es una aplicación de escritorio; este editor independiente cubre las tareas habituales desde el navegador y agrega compatibilidad con Bedrock.

¿Funciona en macOS y Linux sin Mono?

Sí. Es una página web y funciona en cualquier navegador actual de macOS, Linux, Windows, Android o ChromeOS.

¿Puede abrir una región completa como NBTExplorer?

No. Edita un documento NBT por vez. Primero extrae un chunk del archivo .mca y después arrastra aquí la carga útil.

¿Es seguro usarlo con mi única copia del mundo?

Nunca escribe sobre el archivo abierto: los cambios se entregan en una descarga nueva. Aun así, conserva tu propio respaldo, como con cualquier editor.
