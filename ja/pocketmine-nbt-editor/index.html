PocketMine-MP・Bedrockサーバー level.datエディター

Minecraft Bedrock EditionとJava Editionに対応し、一般的なものから小規模なものまで両方の全サーバーコアを扱えます: Vanilla、Paper、Spigot、Purpur、Folia、Fabric、Forge、NeoForge、Mohist、Sponge、Bedrock Dedicated Server、PocketMine-MP、Nukkit、PowerNukkitX、Cloudburst、Dragonfly、Endstone、LeviLaminaなど。全一覧。

BedrockサーバーソフトウェアのPocketMine-MP、Nukkit、PowerNukkitX、Cloudburst、Dragonfly、Bedrock Dedicated Serverは、いずれも8バイトヘッダー付きリトルエンディアン level.dat を worlds/<World>/ から読みます。フォルダー複製後のワールド名、スポーン、ゲームルールを修正したり、最後に書き込んだビルドを確認したりできます。

ワールド名が重複する問題

Bedrockサーバーではよく起きます。2つ目のアリーナを作るため worlds/hub を worlds/hub2 へコピーしても、コンソール、ワールド管理機能、プラグインは両方を hub と表示します。フォルダー名は変わりましたが、LevelName は level.dat 内で変わっていないためです。

表示だけの問題ではありません。内部名でワールドを検索するテレポート、ワールド別設定、保護プラグインは誤ったワールドを参照する可能性があり、管理コマンドも曖昧になります。上へファイルをドロップし、LevelName を新しい名前へ変更してください。

  1. サーバーを停止します。稼働中は保存時に level.dat を書き直し、編集を取り消します。
  2. SFTPまたはパネルのファイルマネージャーで worlds/<World>/level.dat をダウンロードします。
  3. エディターへドロップし、LevelName を新しい名前へ変更して保存します。
  4. 元ファイルをバックアップした上で、ダウンロードしたファイルをアップロードします。
  5. サーバーを起動し、読み込まれたワールドを示すコンソール行を確認します。

コア別の注意点

コアワールドパス注意点
PocketMine-MP (PM5)worlds/<World>/既定ワールドは level-name を server.properties 内で設定して指定します。これはフォルダー名で、LevelName はワールド自身の名前です。
Nukkit / PowerNukkitXworlds/<World>/同じBedrock配置を使い、PNXは同じ場所に独自設定ファイルを追加します。
Bedrock Dedicated Serverworlds/<World>/level-name は server.properties 内でフォルダーを選び、ヘッダーのストレージバージョンは通常10です。
Cloudburst / Dragonflyworlds/<World>/同じ level.dat を読みます。Dragonflyは独自データベースにも状態を保存する場合があります。
WaterdogPE, Geyser—プロキシなのでワールドを保持せず、NBTはネットワークNBTとして通信を通過するだけです。

本番環境を壊さずに作業する

  • ワールドフォルダー全体をバックアップします。level.dat だけのバックアップではなく、問題が起きたときに全体を戻せるようにします。
  • 稼働中のファイルをSFTP上で直接編集しないでください。停止中にダウンロード、編集、アップロードします。
  • 新しいモード用にワールドをコピーする場合、サーバーが読む前に LevelName を変更し、誤った名前をキャッシュさせないようにします。
  • 読み込み後にファイルバーを確認します。検出形式とストレージバージョンを表示します。Bedrockファイルが Bedrock の level.dat 以外なら、誤ったファイルまたは破損の可能性があります。

よくある質問

PocketMine-MPはBedrockと同じlevel.datを使いますか？

はい。PocketMine-MPはBedrockワールド形式を実装し、level.dat は8バイトヘッダー付きリトルエンディアンNBTです。VanillaのBedrockサーバーと同じバイト配置です。

2つのワールドがコンソールで同じ名前になるのはなぜですか？

同じフォルダーからコピーされ、LevelName も同じためです。フォルダー名とタグは独立しているので、タグを変更してください。

サーバーを再起動せずにワールド名を変更できますか？

できません。ワールドはメモリーに読み込まれ、保存時に書き直されるため、稼働中の編集は破棄されます。停止して編集し、再起動してください。

NukkitとPowerNukkitXでも使えますか？

はい。形式、ファイルパス、作業手順は同じです。

BedrockワールドをJavaへ変換できますか？

NBTエディターだけではできません。バイト順だけでなく、タグ配置、ブロックパレット、チャンク保存形式が大きく異なります。専用コンバーターを使い、残ったメタデータの修正にこのエディターを使ってください。
